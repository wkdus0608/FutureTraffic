               혼잡도 예측 시스템


               A Real-Time Traffic Congestion Prediction System Using
               Multimodal Deep Learning



        실제 교통관리 현장에서는 교통 센서와 CCTV가 함께 활용되고 있으나, 단
        기 교통 혼잡도 예측 모델은 주로 차량 속도, 교통량, 도로 점유율과 같은
        시계열 수치 데이터를 중심으로 구성된다. 이에 따라 차량의 공간적 밀집
        상태, 정지 차량 비율, 대기행렬 및 차종 구성 등 CCTV 영상에서 확인할
        수 있는 도로 상황을 예측에 직접 반영하기 어렵다는 한계가 있다.
        본 연구에서는 ITS 국가교통정보센터에서 제공하는 실시간 CCTV 영상과
        차량검지기 데이터를 직접 수집하고, 두 데이터를 결합한 멀티모달 기반
        교통 혼잡도 예측 시스템을 구현하고자 한다. 또한 데이터 수집, 전처리,
        예측 및 저장 과정을 연결하는 실시간 데이터 파이프라인과 웹 대시보드를
        구축한다. 센서 데이터만 사용하는 모델, 영상 특징만 사용하는 모델, 두
        데이터를 결합한 모델을 비교하여 영상 정보가 15분 후 평균속도 예측 정
        확도 향상에 기여하는지 확인하는 것을 목적으로 한다.

        ITS Open API를 이용하여 같은 도로와 방향의 CCTV 영상과 차량검지기
        데이터를 일정 기간 직접 수집한다. 차량검지기 데이터에서는 속도, 교통
        량, 도로 점유율을 사용하고, CCTV와 차량검지기는 도로 링크, 위치, 방향
        및 시간을 기준으로 연결한다. 우선 CCTV 1대를 대상으로 수집 가능성과
        데이터 연결 상태를 확인한 후, 가능할 경우 2~3대로 확대한다.
        CCTV 영상에는 YOLO 기반 객체 탐지 및 추적 기법을 적용하여 차량 수,
        차량 밀도, 정지 차량 비율, 차종 구성 등의 특징을 추출한다. 영상 전체를
        장기간 저장하기보다 추출된 특징값을 일정 시간 단위로 집계하여 저장하
        고, 일부 영상만 검증 목적으로 보관한다.
        센서 시계열에는 LightGBM을 기본 모델로 적용하고, GRU 또는 TCN과 같
        은 경량 시계열 딥러닝 모델을 추가로 검토한다. 최근 30~60분의 센서 및
        영상 특징을 입력으로 사용하여 15분 후 평균속도를 예측한다.
        실시간 데이터 파이프라인은 ITS API를 통해 CCTV와 차량검지기 데이터
        를 자동으로 수집하고, 영상 특징 추출, 데이터 결합, 예측 및 저장 과정을
        순차적으로 수행하도록 구성한다. 모델 학습은 Google Colab의 GPU 환경
        에서 수행하고, 예측 결과와 현재 교통 상태는 웹 대시보드에서 시각화한
        다.
        성능 평가는 센서 데이터만 사용하는 모델, 영상 특징만 사용하는 모델,
        두 데이터를 결합한 멀티모달 모델을 동일한 도로·시간·평가 데이터에서
        비교하는 방식으로 진행한다. 실제 속도와 예측 속도 사이의 MAE와
        RMSE를 측정하고, 데이터 입력부터 예측 결과 생성까지의 처리 시간도
        함께 측정하여 예측 정확도와 실시간 처리 가능성을 평가한다.
