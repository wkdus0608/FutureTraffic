# 교통량 기반 DQN 교차로 신호 제어

AI Hub 71572의 부천 교통량을 SUMO에 적용하고, SUMO-RL·Stable-Baselines3 DQN으로 **석천사거리 `204820` 한 곳**의 신호를 제어합니다. 나머지 신호는 고정신호를 사용합니다.

## 현재 상황 — 2026-10-05 (전체 도로망 환경 검증, 연구용 재학습 보류)

- 원래 연구 범위인 **12개 교차로 전체 환경**을 유지하고, 검증 후 `204820` 한 곳만 제어한다. focused 결과는 단일 교차로 예비 실험으로 보존한다.
- `src/network_environment.py`에서 원본 회전량 → 근거별 이동 대응 → 전체 경로 추정 → 대기열을 이어 가는 연속 실행 → 실제 회전 완료 검사를 수행한다. 부족·초과·미관측 통과·미진입·미완료를 각각 보고한다.
- 곡선 우회전은 상류·곡선·하류 전체 경로로 대응한다. 중앙공원 두 연결은 별도 지도 사본에서 복원한다. 유턴 기록과 신호 칸 대응은 확인되지 않은 가정으로 남기며, 원본 분모에서 지우지 않는다.
- 회전 기록 시각과 도로망 진입 시각을 구분하는 공동 추정 도구를 추가했다. 도착을 녹색에 맞춰 배정하지 않으며, 신호 지연을 제외한 추정만으로 실제 교통을 복원했다고 승인하지 않는다.
- 교차로 **내부** 충돌 검사를 추가하니 기존 전체망 진단의 충돌 0이 4건으로 바뀌었다. 세 내부 대기 위치만 바꾼 사본에서 그 4건은 사라졌지만, 다른 비신호 교차로 충돌 1건이 나타났다. 안전 검증은 아직 통과하지 않았다.
- 두 비신호 교차로 사이의 0.29m 연결에서 상호 교착을 확인했다. 해당 지역만 하나로 합친 가정 사본은 같은 7,044대 시험에서 미진입 365→0대, 종료 잔여 641→30대였다. 배출 시간을 늘리면 모두 도착하지만 충돌 6건은 남는다. 원본과 나머지 12곳 신호를 보존하며, 실제 도로 구조가 검증됐다는 뜻으로 해석하지 않는다.
- 현재 전체 환경은 검증을 통과하지 않았다. 옛 DQN 성능을 최종값으로 인용하지 않으며, 새 연구용 학습·평가는 시작하지 않는다. 원본·예비 결과·모델은 보존한다.

## 이전 상황 — 2026-10-03 (석천사거리 중심 실험 v3.2)

- 도로망 전체에 교통량을 맞추는 대신 **석천사거리에 기록된 회전 1건 = 차량 1대**로 교차로 주변만 시뮬레이션한다. 다른 교차로 미반영 59건은 해결이 아니라 범위 밖이다.
- 이동별 15분 교통량을 15분 동안 무작위로 도착시킨다(시험 4일 모두 기록과 100% 일치).
- 기존 고정신호 = AI Hub 실제 운영 신호(한 현시 밀림 보정). 1분 통과량과 녹색 시간의 상관(0.60~0.79)으로 보정을 확인했다.
- DQN은 보행 최소 녹색·보행 최대 대기·최대 녹색·차량 대기 보장 규칙을 지키며 학습했다(학습 13일, 100,000단계 × seed 3).
- **시험 4일(384개 15분 시간대) 결과**: 차량당 평균 지연 고정신호 52.4초 → DQN 42.1초(−19.7%), 97.4% 시간대에서 DQN이 우세. 다만 길주로 서쪽 좌회전(477706392_02 — 좌표상 동쪽에서 들어오는 접근로) 차량의 19.7%가 5분 넘게 기다리는 단점이 있다.
- 요약: [`docs/석천사거리_DQN_실험결과_20261003.md`](docs/석천사거리_DQN_실험결과_20261003.md), 자동 보고서: `results/focused_204820/v3/report.md`, 실행: `src/focused_experiment.py`, 검사: `tests/test_focused.py`, `tests/test_constraints.py`.

## 데이터와 품질 보고서

- `network.net.xml`: 도로·차로·교차로 연결과 내장 신호를 담은 지도.
- `possible_routes.rou.xml`: 차량이 선택할 후보 경로. `p/b/t/m.xml`은 차종별·시간별 회전교통량.
- `data_quality_summary`: 전체 원본량·반영량·미반영량 요약. `data_quality_by_movement`: 시간·차종·진입→진출별 상세 대조.
- 관측량은 **교차로 통과 횟수**입니다. 한 차량이 여러 교차로를 지나므로 생성 차량 수와 다릅니다. 미반영량은 경로 생성 단계의 차이이며 텔레포트 횟수가 아닙니다.

## 확인한 내용과 남은 문제

- 지도 참조·내부 연결 검사 오류 0. 이는 실제 도로 규제와 모든 교통 조건까지 검증했다는 뜻은 아닙니다.
- 비교한 관련 원본 11개와 차량 기록 1개는 샘플과 동일했습니다. 전체 다운로드만으로 누락이 해결되지 않았습니다.
- 남은 **59건은 4개 교차로의 회전 관계 9개**에 직접 연결이 없는 경우입니다. 지도 오류인지 의도적인 범위 제외인지 아직 확정하지 못했습니다.
- 설명서는 지도 범위에 맞춘 가공을 설명하지만, 회전별 차로·신호 대응표는 없습니다. 추가 검사한 차량 기록 398,845행의 다음 회전·신호·현시 속성도 비어 있습니다.
- 3개 교차로의 외부 신호와 지도 신호 길이가 다르며, 도로 ID 별칭도 공식 확인이 필요합니다. 누락을 숨기거나 근거 없이 연결을 추가하지 않습니다.

## 학습 상태

DQN은 4개 녹색 신호 중 하나를 5초 간격으로 선택하며 황색시간은 3초입니다. 5,000단계 새 학습과 반복 평가를 수행했습니다. 같은 15분 수요의 예비 실험이고, 차로 변경 가정 `lcStrategic=1.5`를 쓴 별도 사본은 기본값으로 채택하지 않았습니다. 실제 도로 성능이나 다른 날짜 일반화는 아직 검증하지 않았습니다.
