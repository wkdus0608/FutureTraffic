
# 실제 현장

VDS: 도로에 깔린 루프·레이더·영상 검지기가 그 지점의 속도·교통량·점유율을 실시간으로 잰다
구간 시간: 하이패스(DSRC)나 번호인식으로 “이 구간을 실제로 몇 분에 지나갔는지”를 보강합니다.
운전자에게 보이는 것: 전광판·내비게이션의 “○○까지 ○분”은 대부분 지금 속도가 이어진다고 가정한 추정입니다. 우리처럼 15분 뒤를 따로 학습하는 모델이 센터 기본 운영은 아닙니다.
CCTV: 사고·공사 같은 돌발을 사람이 눈으로 확인하는 용도가 큽니다. 영상을 YOLO로 풀어서 VDS 위에 얹는 방식은 현장 표준이 아니라, 우리가 실험하는 연구 질문에 가깝습니다.


----
CCTV 후보 : 경부선 판교 1로. 위치가 정확히 일치하며 수도권 교통량 혼잡 변화가 크기 때문
	수도권제1순환선 판교분기점과 이번에 선정한 경부선 판교1은 서로 다른 CCTV

실제 수집은 다음처럼 진행하면 됩니다.
1. ITS API에서 경부선과 판교1에 해당하는 HTTPS HLS CCTV를 찾기
2. VDS 원시자료에서 0010VDE31400, 0010VDS31400만 추출하기
3. 서울 방향 VDS와 CCTV 방향이 맞는지 확인하기
4. 30분 정도 CCTV 영상과 VDS를 동시에 시험 수집하기
