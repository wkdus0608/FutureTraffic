# 석천사거리 강화학습 기반 신호 제어

AI Hub 71572의 부천 교통량으로 석천사거리(신호 `204820`)를 SUMO에 재현하고, 같은 수요·운전자 조건에서 신호 제어 방법을 비교한다. **강화학습으로 학습한 제어 정책을 개선하는 것**이 연구의 중심이다.

DQN의 성과와 성능 정체를 확인한 뒤, **SUMO 탐색으로 더 좋은 행동 경험을 생성하고 이를 신경망이 배우는 방향**으로 접근을 확장했다. 현재는 탐색의 이득을 학습 정책으로 옮기는 과제를 검증하고 있다.

> **현황 기준: 2026-10-25, 진행 기록 164절.** H1을 30만 단계까지 이어 학습해도 검증 지연이 문턱(1.3초) 넘게 줄지 않았다(39.78 → 39.26초, 차이 없음). 그 전 기록(158절): 한 차례 정책 개선 PI1을 완료했으나 개선을 확인하지 못했다. P0 39.30초, 부모 B 39.49초, 새 학생 39.89초다. 정한 범위에서 멈추며 자동 두 번째 라운드는 없다. 모든 성과는 AI Hub 수요를 이용한 SUMO 시뮬레이션 결과다. 실제 도로 성능을 주장하지 않는다.

## 연구 접근의 변화

1. **DQN 제어:** 직접 실행한 경험으로 행동 가치를 학습한다. 공식 모델은 고정신호보다 개선했으나 강한 비교 제어와 격차가 남았다.
2. **비교 기준과 진단:** 단순 제어와 예측 제어 P0를 사용했다. 관측 추가·선택 시점 변경 등 시험한 DQN 설정으로는 격차를 해소하지 못했다. DQN 일반의 한계나 실패 원인을 확정한 것은 아니다.
3. **SUMO 탐색:** 같은 현재 상태에서 여러 첫 행동을 각각 시험하고 이후에는 P0를 따른다. 실제 미래 출발 차량을 제거하고 과거 교통으로 표본 미래를 만든다. 제한된 연속 제어에서 P0보다 나은 행동 경험을 만들었다.
4. **정책 학습:** 저장된 후보별 비용으로 학생을 학습한다. 다른 상황에서도 탐색의 이득을 유지하는 데는 아직 성공하지 못했다.

현재 비용 회귀 학생은 DQN 자체가 아니다. PI1에서는 학생이 직접 만든 상황에서 후보 이후에도 고정 학생이 운영한 미래 비용을 재어 다음 학생을 한 번 학습했다. 탐색·학습의 첫 개선 반복은 실행했으나 실제 연속 제어의 개선을 확인하지 못했다. 12개 교차로 지도에서도 학습 정책이 제어하는 신호는 석천사거리 하나이며, 이웃 11곳은 실제 신호로 둔다.

## 최근 실험: 관측 × 학습 방법 4조합(COMBO) — 개선 미확인

| 관측 | 비용 회귀: 비용을 맞히고 최소 후보 선택 | 직접 정책 최적화: 같은 비용표로 기대 비용 최소화 |
|---|---|---|
| 기존 72칸 | A: 기존 S6 가중치 그대로 | C |
| 기존 + 위치 분포 24칸(96칸) | B | D |

- 자료는 6개 날짜·시간대 묶음의 탐색 경험 **314개**다. 기존 229개와 신규 85개 모두에 같은 새 관측을 붙인다.
- 새 24칸은 이동 8개 × 시간 구간 3개([0, 10), [10, 20), [20초 이상))다. 현재 감지 구간의 움직이는 차량을 **정지선까지 거리 ÷ 도로 제한속도**로 나눠 센다. 실제 도착 시각의 예측은 아니다. 차 수를 20으로 나누고 최대 1로 제한한다.
- 기존 72칸에도 차량 밀도·전체 차량 수가 있다. 새로 더하는 것은 이동별·거리별 분포다. 현재 차량의 회전 의도를 경로로 안다는 가정은 남는다.
- 두 학습 방법 모두 같은 탐색 비용표를 사용한다. DQN 대 다른 강화학습 알고리즘의 비교가 아니다.
- 학생은 좌회전 정체 시점에서만 선택하고 나머지는 P0다. 따라서 최종 평가 대상은 **P0+신경망 혼합 제어**다.
- 같은 16개 평가 조건에서 P0·A·B·C·D를 연속 제어한다. **A보다 개선됐는지와 P0를 넘었는지는 별도 판정**한다.
- 16회는 4개 교통 조건(날짜 2개)의 seed 반복이다. 묶음별 평균·구간도 함께 보고하며 결론은 개발 평가의 단서로 한정한다.

- **결과(10-24, 진행 기록 153절): 이 4조합으로는 개선을 확인하지 못했다.** 평균 차량 지연은 P0 39.30, A 39.96, B 39.49, C 39.75, D 40.43초다.
  - A보다 나아졌다고 판정된 칸이 없다. B +0.47초 [−0.27, +1.22] (대부분 한 묶음 몫), C +0.22초(좌회전 나빠짐)는 '불분명', D −0.47초는 '변화 없음 또는 나빠짐'이다.
  - 네 칸 모두 P0를 넘지 못했다(가장 가까운 B −0.19초, D는 네 묶음 모두 P0보다 나쁨).
  - 관측·학습 효과는 가를 수 없고, 상호작용은 16회 기준 나빠지는 쪽 단서(−1.16초)지만 묶음 4개 구간은 0을 포함한다.
  - 직접 정책 최적화는 동쪽 좌회전 지연(119.8 → 약 108초)을 남쪽 좌회전(100.0 → 116~119초)으로 옮겼다. 전체 지연은 줄지 않았다.
  - 실행 확인(재생 9개 일치, 314개 관측, P0·A가 이전 결과와 동일, 누락·충돌 0)은 모두 통과했다. 결과: `results/explore/combo_20261024/`.

실행 전 기준과 정정은 진행 기록 148~151절, 결과는 153절, 구현은 [explore_combo.py](src/explore_combo.py)다.

## 최신 완료: 한 차례 정책 개선(PI1) — 개선 미확인

**10-25 결과: 정책 개선 미확인.** 수요 이력 29칸은 사전 기준을 통과하지 못해 96칸 부모(B)를 유지했다. 부모가 방문한 학습 상태 48개에서 후보를 비교했고, 독립 확인 미래의 이득 합 +2,241대·초·3묶음 중 2개 양수·22개 선택 변경으로 학생 한 번 학습 기준을 통과했다. 그러나 실제 연속 제어에서는 그 이득을 유지하지 못했다.

| 정책 | 평균 차량 지연 | 부모보다 줄인 지연 | P0보다 줄인 지연 |
|---|---:|---:|---:|
| P0 | 39.30초 | — | — |
| 부모 B | 39.49초 | 기준 | −0.19초 |
| PI1 학생 | 39.89초 | **−0.40초** | **−0.59초** |

판정 뒤 추가 학습 없이 고정 가중치로 검사한 결과, 새 학생은 학습 장면 48개 중 탐색 선택과 47개가 같았고 선택용 미래의 예상 이득 99.86%를 회수했다. 배운 장면을 맞히는 것은 확인했으나 실제 연속 제어 개선은 아니며, 실패 원인을 일반화 하나로 확정하지 않는다.

부모 대비 줄인 지연의 4묶음 95% 구간은 [−1.37, +0.57]초, 개선 묶음은 1/4다. 개선을 확인하지 못했으며 일반적인 악화가 확정된 것은 아니다. 동쪽 좌회전은 117.73 → 112.72초로 줄었지만 남쪽은 98.59 → 105.04초로 늘어, 부모 대비 5초 이내 조건도 통과하지 못했다. 네 수요 조건의 seed 반복을 다시 쓴 개발 평가이며 새 날짜 최종 시험이 아니다.

누적 비용은 **33,070.86 CPU초 / 상한 36,000초**다. 요약의 평가 48개에서 누락·미완료·규칙 개입·충돌·300초 초과는 모두 0이다. 원시 평가 48개가 요약과 같고 P0·부모의 기존 32개 결과도 재현됐다. 코드 지문·모델 10개 해시·실험 지문·CPU 장부 대조를 통과했다. 결과는 `results/explore/policy_iter_20261025/`이며 근거는 진행 기록 156~158절이다. **자동 추가 수집·두 번째 라운드는 시작하지 않는다.**

- 공식 시험 4일과 추가 시험 12일은 이미 사용했다. 이후 실험은 학습 제외 개발 평가·추가 탐색으로 기록한다.
- 학습 자료에서 예상 이득을 96~98% 회수했다는 수치는 선택 정확도가 아니다.
- 저장 장면의 후보 비용 합은 연속 제어의 차량당 지연과 다른 지표다.
- P0의 성능은 이 문제의 최적값이 아니다. 탐색기의 개선을 학생 신경망의 개선으로 보고하지 않는다.
- 환경 주 결과는 `pet1`이며 세부 설정·공식 모델은 [v6 설정](docs/실험설정_v6.md)을 따른다. 감응식은 현재 주 비교에서 제외했다.
