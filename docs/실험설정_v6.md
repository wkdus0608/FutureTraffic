## 1. 무엇을 비교하나

| 정책 | 내용 |
|---|---|
| 고정신호(원자료) `fixed` | 그날 AI Hub 실제 운영 신호 그대로(v5와 같음). AI Hub 기록에는 전적색이 한 번도 없다 |
| 고정신호(보정) `fixedc` | 원자료에 전환 규칙의 전적색을 넣는다. 끝나는 녹색의 마지막 R초를 빼서 황색 뒤 전적색 R초로 두므로 하루 시간표(다음 녹색이 켜지는 시각)는 원자료와 같다. 1초 기준에서는 길주로 직진 → 길주로 좌회전 한 곳만 바뀐다(길주로 직진 녹색 중앙값 69초 중 2초, 3%) |
| 단순 제어 `greedy` | v5와 같다(학습 없음, 회전 계획을 아는 참고 기준). 전환할 때 규칙의 전적색을 거친다 |
| DQN `dqn` | v5와 같은 학습기·관측·보상. 전환할 때 규칙의 전적색을 거치고, 운영 규칙(최소 녹색·보행 최대 대기)이 전적색 시간까지 넣어 계산한다 |
| 감응식 `actuated` | **비교에서 뺀다**(10-15 결정). v5부터 학습·검증 15일 평균에서 무너지고(길주로 동쪽 좌회전 600초대), 전적색을 넣으면 보행 한도를 어긴다(최대 녹색 계산에 전적색을 넣지 않은 구현 공백). 한계로 기록한다 |

## 2. 새로 정한 것

### 2.1 전환 규칙(전적색) — `config/transition_rules.json`

녹색 i에서 j로 바뀔 때 황색 4초(고정신호는 기록대로 3·4초) 뒤에 두는 전적색(모든 방향 적색, 우회전 양보 녹색은 유지) 길이다.

| 전환 | 실제 신호에 있나 | v5 15일 가장 작은 간격 | pet1 | pet1_5 |
|---|:---:|---:|---:|---:|
| 석천로 좌회전 → 길주로 좌회전 | | −0.8초 | 2초 | 3초 |
| 길주로 직진 → 길주로 좌회전 | ○ | −0.2초 | 2초 | 2초 |
| 길주로 좌회전 → 석천로 좌회전 | | −0.2초 | 2초 | 2초 |
| 석천로 직진 → 길주로 직진 | | +0.4초 | 1초 | 2초 |
| 길주로 직진 → 석천로 좌회전 | | +0.5초 | 1초 | 1초 |
| 길주로 직진 → 석천로 직진 | | +0.7초 | 1초 | 1초 |
| 길주로 좌회전 → 길주로 직진 | | +1.1초 | 0초 | 1초 |
| 석천로 직진 → 석천로 좌회전 | ○ | +1.1초 | 0초 | 1초 |
| 길주로 좌회전 → 석천로 직진 | ○ | +1.4초 | 0초 | 1초 |
| 석천로 좌회전 → 길주로 직진 | ○ | +1.7초 | 0초 | 0초 |
| 석천로 좌회전 → 석천로 직진 | | +1.9초 | 0초 | 0초 |
| 석천로 직진 → 길주로 좌회전 | | +2.3초 | 0초 | 0초 |

- 간격(통과 후 간격, PET) = 시작하는 녹색 첫 차의 앞끝이 겹치는 구역에 닿은 시각 − 끝나는 녹색 마지막 차의 뒤끝이 그 구역을 빠져나간 시각. 합류는 두 길이 만나는 점에서 잰다.
- 규칙 = ceil(기준 − 그 전환의 가장 작은 간격). 기준은 pet1 1초, pet1_5 1.5초다. 간격은 v5 학습·검증 15일, 실행 162개, 전환 약 33만 번에서 쟀다.

### 2.2 석천로 북쪽 도로 연장 — `config/environment_v6.json`

- AI Hub 지도는 석천로 북쪽 진입로가 정지선 58m 위(`477706911_01_01` 시작)에서 끝난다. 그 도로(3차로)의 시작점을 같은 방향으로 240m 늘려 정지선에서 298m가 되게 했다(줄 설 수 있는 차 약 23대 → 119대).
- 그 구간의 실제 모양은 자료에 없어 곧은 3차로로 가정했다. 차량 수·차종·정지선 도착 시각은 그대로이고, 출발 시각만 자유 주행 시간만큼 앞당긴다.

## 6. DQN 재학습 뒤 검증 결과(검증 2일, 67절)

차량당 지연은 무작위 도착, 2일 차량 가중이다. DQN은 seed 5개 평균 ± 표준편차다.

| | none | pet1 | pet1_5 |
|---|---:|---:|---:|
| 고정신호 원자료 | 46.28초 | 46.28초 | 46.28초 |
| 고정신호 보정 | — | 47.31초 | 47.72초 |
| 단순 제어 | 37.51초 | 39.69초 | 40.29초 |
| **DQN** | 39.74 ± 0.77초 | **42.25 ± 0.65초** | 43.02 ± 0.71초 |
| DQN 두 차가 겹친 전환(간격 < 0) | 1 | 0 | 0 |
| DQN 아슬아슬한 전환(간격 < 1초) | 92 | 3 | 0 |

- 전환 횟수는 DQN 실행 20개(검증 2일 × seed 5개 × 도착 2가지)의 합이다.
- 주 결과(pet1): DQN은 보정 고정신호보다 5.06초(10.7%), 원자료보다 4.03초(8.7%) 짧다. 규칙의 비용은 순서를 바꾸는 제어가 더 낸다(none → pet1: DQN +2.51초, 단순 제어 +2.18초, 고정 +1.03초).
- 대가: DQN의 300초 초과가 none 0대에서 pet1 seed당 7대(고정 7대)가 됐고, 무리 도착에서는 10.6대(고정 3대)다. 좌회전이 대가를 치르는 모양은 v5와 같다(길주로 동쪽 좌회전 고정 93.2초 → DQN 142.9초).
- 무리 도착에서 pet1 DQN(44.28 ± 0.97초)과 원자료 고정(45.39초)의 차이는 seed 흩어짐 수준이다.
- 석천사거리 안 충돌은 0건이다. 운영 규칙이 DQN의 판단을 바꾼 경우와 보행 한도 초과도 0이다.
- seed 사이 표준편차가 v5(0.3초)보다 커졌다(0.65~0.97초). 미리 정한 고르는 규칙의 '0.6초'(v5 표준편차의 2배)는 같은 정의로 약 1.3초가 되므로, 설정 비교 실험 전에 다시 적는다.

## 7. 한계(보고서에 적을 것)

- 실제 도로에 전적색이 있는지 AI Hub 기록으로 알 수 없다. 그래서 원자료판과 보정판을 둘 다 보고한다.
- 전적색이 메우는 몫에는 SUMO 모형의 한계도 섞여 있다. 09-28 충돌에서 SUMO는 빠져나가는 버스 뒷부분을 상대 차로 보지 않았다.
- 두 규칙 모두 "모든 전환 간격 1초 이상"을 엄밀히는 채우지 못한다. pet1은 8번, pet1_5는 4번이 남는다. 대부분 정지선을 1.2~1.3m/s로 기어 들어간 트럭·버스 같은 드문 경우다.
- DQN도 pet1에서 아슬아슬한 전환이 3번 남는다(검증 2일, 실행 20개). 모두 정지선을 8.4~11.2m/s로 넘은 버스이고, 그중 0.53초는 pet1 전적색이 0초인 길주로 좌회전 → 길주로 직진에서 나왔다. pet1_5에서는 0번이다.
- 북쪽 도로 연장 구간의 모양은 가정이다.
- 감응식은 비교에서 뺐다.
