## 1. 요약

**목표.** 고정신호보다 차량당 지연을 최대한 줄이는 모델을 강화학습으로 만든다. 시연 때는 저장한 신경망과 안전 규칙만으로 돈다.

**지금 위치.** 계획기를 실행 경로에서 완전히 뺀 신경망이 12판 점검에서 계획기와 비슷한 수준까지 왔다. 아직 12판·모델 1개 값이고, 대부분 흉내의 몫이라 강화학습 성과는 아니다.

| 세계 | 신경망만 모델 | 고정신호 대비(12판) | 같은 12판의 계획기 | 84상황 어림 |
|---|---|---:|---:|---:|
| 무리 도착 | N2: t20을 흉내 | −26.0% | TM4 −26.3% | −25~−27% |
| 무작위 도착 | Rn: S2A_pre를 흉내 | −27.7% | M4 −26.7% | −25~−26% |

같은 설정이라도 난수에 따라 값이 흔들린다. TM4 흉내 모델 3개는 같은 12판에서 −20.9~−24.5%(평균 −23.1%)였다. 입력 자체는 점검에서 문제를 찾지 못했다(3절).

**계획.** 이 신경망을 출발점으로, 신경망이 직접 운전하고 같은 순간의 다른 녹색과 짝 비교해 확실한 곳만 고치는 라운드를 세계별로 반복한다. 처음부터 배우는 DQN도 같은 라운드로 돌려 흉내 출발과 비교한다.

| 단계 | 하는 일 | 답할 질문 | 계산량(어림) |
|---|---|---|---:|
| 0 | 신경망만 실행기를 정식 코드로 만든다 | 계획기 없이 같은 결과가 나오나 | 맥, 시험 |
| 1 | 출발 모델 7종을 84상황에서 잰다 | 신경망만으로 실제 얼마나 되나 | 85 CPU-시간 |
| 2 | 12개 지도에 올려 본다 | 실제 연동 도로망에서도 통하나 | 35 CPU-시간 |
| 3 | 강화학습 라운드 + 처음부터 DQN | 강화학습이 더 올리나, 흉내 출발이 발목을 잡나 | 800 CPU-시간 |
| 4 | 최종 판정 | 새 차량 배치에서도 유지되나 | 85 CPU-시간 |
| 5 | 규칙 완화, 시연 | 규칙을 풀면 얼마나 더 되나, 화면에서 신경망만으로 도나 | 180 CPU-시간 + 맥 |

**기대(추정, 약속 아님).** 신경망만으로 무리 도착 −26~−29%, 무작위 도착 −25~−27%. 강화학습의 몫은 0으로 나올 수 있다. 보행 최대 대기를 풀면 약 3%포인트 더 줄어든다. 12개 지도에서는 숫자가 훨씬 작을 가능성이 크다.

**하지 않는 것.** DQN·PPO로 흉내 모델 미세조정, 문턱 없이 선택지 넓히기, 12곳 동시 제어(범위 변경이라 교수님 상의 전), RELAX0 무리 세계 D 다시 돌리기.

**용어.**

|---|---|

| 계획기 | 120초 앞을 계산해 녹색을 고르는 프로그램. P0(기본), M4(좌회전 2배), TM4(M4 + 이웃 시간표), OM4(정확한 도착을 앎) |

| 무리 도착 세계 | 단독 지도에서 동쪽 차만 이웃 신호(204822) 녹색에 맞춰 출발시킨 모형 |
| 12개 지도 | 이웃 신호까지 실제로 있는 도로망 |
| 84상황 | 7일 × 시간대 6개 × 차량 배치 2개. 판마다 준비 30분(모든 제어가 실제 신호) + 제어 60분 + 꼬리 15분 |

## 2. 목표와 성공 기준

### 주 지표

같은 상황·같은 차에서 **고정신호 대비 차량당 평균 지연 감소율**(차량 가중)을 세계별로 잰다. 고정신호는 보정 고정신호(FIXC)이고, 꼬리 15분까지 고정신호다.

| 수준 | 내용 |
|---|---|
| 기본 | 신경망만 모델이 84상황에서 오늘 점검 전까지의 최고(N1, 12판 −23.9%)를 넘는다 |
| 목표 | 같은 세계 계획기(무리 TM4 −26.6%, 무작위 M4 −24.9%)와 같거나 낫다. 필수 조건은 아니다 |
| 도전 | 강화학습 라운드의 몫이 0보다 크다(최종 − 출발점, 날짜 t95 하한 > 0) |

함께 적는 부작용은 300초 넘게 늦은 차, 확인 안 된 충돌, 동쪽·남쪽 좌회전, 보행 대기다. 고정신호보다 나쁜 항목은 숫자로 드러낸다. 예를 들어 무리 세계에서 TM4의 동쪽 좌회전은 85.3초로 고정신호 68.5초보다 길다.

### 시연 조건

- **실행 때 도는 것:** 신경망, 입력 계산(감지값·규칙 상태·이웃 시간표·동쪽 도착 추정), 안전 규칙(허용 녹색 계산).
- **실행 때 없는 것:** 계획기와 그 출력, 실행 중 되돌려 굴리기, 실제 미래 차량 정보, 꼬리 P0.
- **남는 가정(보고서에 적음):** 회전 의도를 SUMO 경로에서 읽는다. 이웃 시간표를 미리 안다. 둘 다 실제 도로의 센서가 그대로 주는 값은 아니다.

### 무엇을 강화학습이라 부르나

- **흉내:** 선생님의 행동을 맞힌다. 강화학습이 아니다. 흉내만 한 값은 강화학습 성과로 쓰지 않는다.
- **강화학습:** 시뮬레이션 결과로 정책을 고친다. 같은 순간의 후보를 되돌려 굴려 짝 비교하고 고치는 정책 반복도 여기에 든다.
- **N2처럼 섞인 경우:** t20의 판단은 되돌려 굴린 결과에서 왔지만, N2는 그것을 흉내로 옮겼다. N2 전체를 강화학습 값이라 하지 않고, N2 − N1만 '되돌려 굴린 판단이 옮겨진 몫'으로 적는다.

## 4. 설계 원칙

1. **계획기는 학습 때만 쓴다.** 선생님 라벨을 만들 때는 써도 된다. 실행 경로에는 없다.
2. **많이 바꾸지 않는다.** PT1·PI R1은 많이 바꿀수록 나빠졌고, t20은 6%만 바꿔 나아졌다. 모든 라운드에 문턱을 둔다.
3. **신경망이 운전한 상태에서 배운다.** 지금까지의 학생은 계획기가 운전한 상태만 봤다. 실행 때 만나는 상태는 다르다.
4. **세계별로 배운다.** 12개 지도가 어느 세계에 더 가까운지는 2단계에서 잰다.
5. **채택은 한 시간 결과로만 한다.** 5분 점수는 PT1·PI R1에서 부호가 뒤집혔다. 점수는 후보를 고르는 데만 쓰고, 채택은 검증 날짜의 한 시간 SUMO로 정한다.
6. **규칙은 고정한다.** 지금 규칙으로 끝낸 뒤 규칙 완화를 따로 재서 규칙의 몫을 분리한다.
7. **날짜를 아껴 쓴다.** 학습 6일, 검증 2일, 개발 7일, 최종은 새 차량 배치. 라운드 결정에 개발 84상황을 쓰지 않는다.

날짜 나누기는 모델을 만들기 전에 고정한다.

| 용도 | 날짜 | 쓰는 곳 |
|---|---|---|
| 학습 6일 | 0812, 0822, 0907, 0926, 1030, 0909 | 신경망·학생 학습 |
| 검증 2일 | 0928(평일), 0814(주말) | 문턱·라운드 채택 |
| 개발 7일 | 0811, 0819, 0823, 0906, 0813, 0820, 0911 | 84상황 평가, 차량 배치 E1·E2 |
| 최종 | 개발 7일의 새 차량 배치 F1·F2 | 4단계에서 한 번 |

0928을 검증으로 뺀 이유는 12개 지도의 검증 날짜가 0928·0813이라서다. 이렇게 나누면 새 신경망은 두 날짜 모두 학습에서 보지 않는다. 선생님(PT1·S2A_pre)은 8일로 학습된 그대로 쓰므로 검증 날짜가 선생님을 통해 조금 샌다. 최종 판정은 다른 날짜라 영향이 없다.

## 5. 단계별 계획

### 0단계: 신경망만 실행기

오늘 작은 코드로 먼저 확인했다(`results/explore/nn_only_20261101/analysis/planner_free_probe.py`). 계획기를 부르면 멈추게 막고 돌렸다.

| 확인(각 12판) | 무리 세계 N2 | 무작위 세계 Rn |
|---|---:|---:|
| 계획기 호출 | 0회 | 0회 |
| 제어 60분 신호가 기존 경로와 같음 | 12/12 | 12/12 |
| 같은 차 | 12/12 | 12/12 |
| 꼬리까지 신경망, 고정신호 대비 | −26.0% | −27.7% |
| 꼬리 P0 대비 손해 [t95] | 0.03초 [−0.00, +0.06] | 0.06초 [−0.00, +0.13] |
| 판당 시간(맥 4판 동시) | 74초(기존 143초) | 80초(기존 147초) |

마지막 15분을 P0에 기대던 문제는 작았고, 판당 시간은 절반이 됐다. 남은 일은 다음과 같다.

- `src/`에 정식 실행기를 만든다. 잠긴 파일과 기존 실험 코드는 고치지 않는다.
- 시험으로 막는다: 계획기를 부르면 실패, 기존 경로와 신호 대조, 입력 칸 순서.
- 입력 칸은 그대로 둔다: 무리 세계 120칸(감지 80 + 동쪽 도착 추정 16 + 이웃 시간표 24), 무작위 세계 80칸. 크기는 학습 날짜 기준으로 표준화하고, 그 평균·표준편차를 모델 파일에 함께 저장한다.
- 저장을 늘린다: 평가 일부 판의 입력 벡터(학습 때와 실행 때 입력이 얼마나 다른지 계속 재기 위해).
- 계획기 없는 학생의 표준오차 계산을 고친다. 지금은 기준 녹색을 바꿔도 표준오차가 TM4 기준 그대로다.

**끝난 기준:** 시험 통과, 12판 신호 대조 통과, Colab과 맥의 결과 일치.

### 1단계: 출발 모델을 84상황에서 잰다

모든 새 모델은 학습 6일로 다시 만든다. 12판에 쓴 파일럿 모델은 참고로만 남긴다. 후보당 모델 3개, 84상황, 꼬리까지 신경망이다. 표준화와 학습 횟수는 모든 후보에 같게 적용해, 후보 간 차이가 자료와 선생님에서만 나오게 한다.

| 이름 | 세계 | 만드는 법 | 재는 몫 |
|---|---|---|---|
| N1 | 무리 | TM4 흉내(PLATOON1 자료) | 기준 |
| N2 | 무리 | t20 흉내(같은 자료) | N2 − N1: 되돌려 굴린 판단이 옮겨진 몫 |
| N4 | 무리 | N1 + 계획기 없는 학생(무게 25, 자료 기준 바꾸는 비율 10% 문턱) | N4 − N1: 강화학습의 첫 몫 |
| N5 | 무리 | t20 흉내 + 자료 강화 | N5 − N2: 자료 강화의 몫 |
| Rn | 무작위 | S2A_pre 흉내(PI R1 자료) | 기준 |
| RnS | 무작위 | Rn + 계획기 없는 학생(같은 규칙) | RnS − Rn: 강화학습의 첫 몫 |
| Rn2 | 무작위 | S2A_pre 흉내 + 자료 강화 | Rn2 − Rn: 자료 강화의 몫 |

**자료 강화.** 선생님 라벨에는 되돌려 굴리기가 필요 없으므로 자료를 값싸게 늘릴 수 있다. 다만 TM4 흉내에서 모든 결정(4배)과 표준화로 바꿔도 한 시간 평균은 구분되지 않았다(3절). 큰 이득을 기대하지 않고, 비용이 작고 모델 폭을 줄일 단서가 있어 후보로 둔다. 신경망 운전 상태의 재라벨은 아직 잰 적이 없다.

1. 선생님이 운전한 판의 모든 결정을 기록한다(판당 약 4분). 시간대를 고르게 뽑고 첨두를 더 넣는다. 12판에서 TM4보다 뒤지는 몫이 07:30·17:30에 몰렸고(−2.5~−3.9초, 다른 시간대 −0.1~−1.4초), 21시 이후 자료는 64판 중 1판뿐이다.
2. 신경망이 운전하고 선생님이 라벨을 붙이는 라운드를 3번 돈다.
3. 틀리면 비용이 큰 결정에 무게를 더 준다. 학습 횟수는 학습 날짜 안에서 고른다. 지금의 200번은 과하다(보류 일치율 30번 79.9%, 200번 77.5%).
4. 검증 날짜의 한 시간 결과로 몇 번째 라운드 모델을 쓸지 고른다.

**읽기.**

- 세계별로 평균 지연이 가장 짧은 모델을 3단계 출발점으로 삼는다. 차이가 0.3초 안이면 부품이 적은 쪽을 고른다.
- 같은 세계 계획기보다 0.5초 넘게 뒤지면 3단계 전에 라벨 라운드를 한 번 더 돈다.
- 어느 세계든 가장 좋은 모델이 −22%보다 못하면 12판 값이 크게 과대했던 것이다(12판 값에서 약 2초가 줄어든 셈으로, 12판 해상도 1~1.6초를 넘는다). 3단계로 가지 않고 사용자와 다시 정한다.

12판을 이미 본 뒤 후보를 정했으므로 이 84상황은 개발 비교다. 성과로 말하는 숫자는 4단계의 새 배치에서 낸다.

### 2단계: 12개 지도 점검

세계별 최고 모델 2개를 실제 연동 신호가 있는 12개 지도에 올린다. 석천사거리만 신경망이 맡고 이웃 11곳은 실제 신호다.

- **범위:** 검증 2일 46조각 × seed 5개 = 후보당 230판(seed마다 모델을 돌려 씀). 기존 기준값과 같은 조건이다.
- **코드:** 12개 지도 평가기는 제어기 자리를 바꿔 끼울 수 있어 P2와 같은 방식으로 넣는다. 평가 코드는 고치지 않는다.
- **비교:** 이미 있는 값(구간 지연, 차 가중)과 비교한다. TM4는 12개 지도에서 잰 적이 없어 새로 잰다. 신경망이 낮을 때 선생님 탓인지 옮겨지지 않은 탓인지 가르기 위해서다.

|---|---:|---:|
| 보정 고정신호 | 56.48초 | 기준 |
| DQN B12 | 53.76초 | −4.8% |
| 선생님 DQN | 53.15초 | −5.9% |

| P0 | 51.15초 | −9.4% |
| P2 | 48.69초 | −13.8% |

- **함께 적는 것:** 도로망 지연, 흔들리는 조각(09-28 08시)을 뺀 값, 300초 초과, 충돌.
- **이 단계가 답하는 다른 질문:** 무리 세계 모델과 무작위 세계 모델 중 어느 쪽이 실제 도로망에서 나은가. 이 답이 주 경기장을 정하는 근거가 된다.

이 단계를 라운드 앞에 두는 이유는 800 CPU-시간을 쓰기 전에 단독 지도 학습이 도로망으로 옮겨지는지 알기 위해서다.

**준비(11/03, 진행 기록 266절):** 후보는 N5·Rn이다. Rn의 짝 계획기가 없어 M4를 더해 TM4·M4를 새로 잰다(920판). 12개 지도는 맥과 Colab의 값이 달라 모든 판을 Colab에서 돌린다. 코드 `src/explore_nn12.py`, 노트북 `notebooks/NN12_*.ipynb`. 11/03 본 실행에서 N5·TM4의 23시 20판이 기록 코드 오류로 실패해 그 판만 정정 노트북 `NN12_*_fix1`로 다시 돌린다(진행 기록 268절). 읽는 법은 그대로다.

**결과(11/03, 진행 기록 270절, 흉내 값, 검증 2일 개발 비교):**

| 제어 | 구간 지연 | 보정 고정신호 대비 | 도로망 지연(조각 평균) | 도로망 지연(차 가중) |

- 읽기: 후보 N5가 P2와 2.2초 안이라 단독 지도 학습을 계속하고 12개 지도는 평가로 쓴다. N5·Rn 모두 '옮겨짐'이다. N5 − Rn +2.59초 [+1.62, +3.56]로 실제 지도에서는 무리 세계 모델이 낫다.

- 구간에서 줄인 총 지연의 약 6%만 도로망에 남는다(계획기는 −12~+19%). 3단계의 채택 기준은 단독 지도 그대로지만, 12개 지도 값을 말할 때는 구간과 도로망을 함께 적는다.
- 원인(맥 12조각, 판정 아님, 진행 기록 271절): 서→동 직진 차가 석천사거리를 지난 뒤 다음 신호(204822) 앞 도로에서 더 기다린다. 판당 33,115차·초로 도로망 손실 대부분이 이 한 도로에서 나오고, 다른 차의 통행 지연은 거의 그대로다. 단독 지도에는 이 신호가 없어 라운드의 라벨에도 들어가지 않는다.
- 12개 지도 구간 지연 계산의 오류(진행 기록 271절): 평가가 끝날 때 아직 구간 안에 있는 차를 지연 0으로 센다. 고치면 고정신호가 더 길어져 감소율이 조금 커진다(맥 12조각에서 N5 −9.3 → −10.3%, TM4 −18.1 → −18.6%). 기존 12개 지도 값은 이 오류를 포함한 값이고 약간 보수적이다. 4단계의 12개 지도 평가에서 고친 계산을 함께 낸다.

### 3단계: 강화학습 라운드

#### 3A. 흉내 출발 라운드(세계별)

3라운드를 기본으로 하고, 3라운드에서도 오르면 더 간다. 한 라운드는 다음과 같다.

1. **운전:** 지금 신경망이 학습 6일 48판을 운전한다. 라운드마다 새 시간대·새 차량 배치를 쓰고, 시간대를 고르게 뽑되 첨두를 더 넣는다.
2. **짝 비교:** 고를 수 있는 순간의 25%에서 허용 녹색을 모두 같은 표본 미래 8개로 300초 굴린다. 뒤도 지금 신경망이 잇는다.
3. **저장:** 이동별 지연, 150·300·600·900초 값(900초는 1라운드의 일부 지점만), 끝 순간 멈춘 차 수. 라벨을 바꿔도 다시 굴리지 않게 한다.
4. **학습:** 계획기 없는 학생이 '지금 녹색 대비 녹색별 이득'을 배운다. 자료는 라운드마다 쌓는다. 앞 절반 미래로 배우고 뒤 절반으로 채점한다.
5. **문턱:** 자료 기준 바꾸는 비율 5·10·20%에 해당하는 문턱 후보를 검증 날짜의 한 시간 결과로 고른다. 문턱 2.0을 그대로 복사하지 않는다.
6. **쌓기:** 새 정책 = 지금 신경망 + 학생. 예측 이득이 문턱 이상일 때만 녹색을 바꾼다. 신경망 구조는 64-64를 유지하고, 라운드마다 하나씩 쌓는다. 한 신경망으로 합치는 것은 검증에서 나빠지지 않을 때만 한다.
7. **채택:** 검증 약 80상황(2일 × 시간대 21개 × 배치 2개)에서 지금 정책과 한 시간 짝 비교를 한다. 평균 +0.2초 이상이고 t95 하한 > 0이면 오른 것으로 보고 채택한다. 두 라운드 연속 못 오르면 멈춘다.

1라운드에서 정할 것은 라벨이다. 무게 25·75, 굴림 길이 150·300·600·900초 가운데 한 시간 결과와 가장 잘 맞는 조합을 검증 날짜에서 고른다. 모델 하나로 후보를 추린 뒤 모델 3개로 확인한다.

학생은 난수만 다른 3개를 만들지만 운전은 신경망 1개가 맡는다. 3개의 차이는 진짜 모델 차이보다 작을 수 있어 그렇게 적는다.

**1라운드 준비(11/03, 실험 NN3, 진행 기록 271절). 위 내용과 달라진 곳:**

- **출발 모델을 먼저 고른다.** 12개 지도에서 N5가 뒤진 새벽·심야 기록 48판을 더한 N6를 만들어, 새벽 검증에서 0.5초 이상 짧고 낮 검증에서 0.2초보다 더 길지 않으면 N6로 간다. 흉내이고 강화학습이 아니다.
- **운전은 모델 3개가 돌아가며 맡는다.** 모델 3개의 폭을 진짜 폭으로 재고 모델별 짝 비교를 하려는 것이다. 시뮬레이션 비용은 같다.
- **자료는 60판이다.** 날짜당 10칸(기존 8칸 + 새벽 1 + 심야 1).
- **굴림은 600초다.** 표시 지점은 30·60·150·300·600초이고(30·60초는 '당장의 이득' 질문, 264절), 해시로 고른 10% 지점만 900초까지 굴려 길이별 일치를 본다.
- **고르기:** 라벨 10개를 비율 10%로 24상황 × 모델 3개에서 거르고, 상위 3개 라벨의 비율 5·20%를 더 잰 뒤, 상위 2개를 새 배치 84상황 × 모델 3개에서 확인한다.
- **동쪽 출구 시각을 저장한다.** 나중에 204822 앞 대기를 라벨에 넣을 때 다시 굴리지 않기 위해서다. 이번 고르기에는 쓰지 않는다.
- **무작위 세계 라운드와 3B는 1라운드 뒤에 준비한다.** 3B는 1라운드에서 고른 라벨을 쓰고, 무작위 세계는 기대 이득이 작아서다(정확한 도착을 알 때 여지 +0.42초, 12개 지도 N5 − Rn +2.59초).
- **신경망 크기는 64-64를 유지한다.** 28,716결정으로 다시 재도 256-256이 낫지 않다(일치 78.7~78.8% 대 79.2~79.5%, 후회 37.2~37.4 대 33.5~35.5).

#### 3B. 처음부터 DQN(무리 세계)

"흉내에서 시작하면 정체되지 않나"에 직접 답하기 위한 비교군이다. 흉내 뒤 DQN·PPO 미세조정은 네 번 모두 정체됐다. 3A는 미세조정이 아니라 짝 비교와 문턱으로 고치는 방법이고, 출발 정책을 넘은 것은 지금까지 이 방법(t20)뿐이다. 그래도 정체될 수 있어 선생님 없는 출발과 직접 비교한다.

- **출발점:** 선생님 없이 H1 설정(n = 10 + Double, 할인율 0.99) DQN을 학습 6일에서 난수 3개로 30만 단계 학습한다. 입력은 3A와 같다.
- **라운드:** 3A와 같은 방법·같은 시뮬레이션 예산.
- **비교:** 3A 최종과 3B 최종을 검증 날짜에서, 이어 84상황에서 잰다. 선생님 자료를 모은 비용은 따로 적는다.
- **범위:** 무리 세계만 먼저 한다. 무리 세계에서 3B가 3A를 넘으면 무작위 세계도 돌린다.

### 4단계: 최종 판정

모델을 잠근 뒤 한 번만 잰다.

| 대상 | 범위 |
|---|---|
| 세계별 최종 모델, 출발 모델 | 84상황(E1·E2) + 새 차량 배치 84상황(F1·F2), 모델 3개 |
| 고정신호, 같은 세계 계획기 | F1·F2에 새로 잰다(기존 C1·C2에는 고정신호 실행이 없다) |
| 12개 지도 | 세계별 최종 모델 230판씩 |
| 무리 세계 시간표 어긋남 | 시간표를 일부러 어긋나게 한 조건 84상황. 무리 세계는 시간표가 무리를 만든 규칙과 같아 너무 유리할 수 있다 |
| 꼬리 P0 | 최종 모델을 꼬리 P0로도 재 기존 표와 잇는다 |

보고할 것은 고정신호 대비 감소율, 강화학습의 몫(최종 − 출발, 짝 비교), 부작용 표다. 과거 결과와 이어 보도록 ARENA3 판정도 참고로 계산하지만 관문으로 쓰지 않는다.

AI Hub 자료 31일은 모두 이미 썼다. 처음 보는 날짜는 더 없다. 그래서 개발 7일과 C1·C2를 '처음 보는 시험'이라 부르지 않는다. 시험 4일·새 12일을 다시 쓸지는 11절의 결정 사항이다.

### 5단계: 규칙 완화와 시연

**규칙 완화(지금 규칙의 결과가 나온 뒤).** 보행 최소 녹색은 도로교통공단 기준(7초 + 횡단 길이 ÷ 1.0 m/s)이라 풀지 않는다. 푸는 후보는 보행 최대 대기(B: 155·120 → 200·155초, 지금 값은 실제 운영의 99분위)다.

1. 최종 모델을 규칙 B에 그대로 올려 잰다.
2. 선생님을 규칙 B로 다시 돌려 라벨을 받고 1라운드를 더 돈다.
3. 규칙의 몫을 학습의 몫과 나눠 보고한다. 보행 대기 증가(무작위 세계 길주로 횡단 51 → 66초)와 무작위 세계 B에서 나온 미확인 충돌 1건을 함께 적는다. 시뮬레이션에 보행자는 없다.

무리 세계는 좌회전 최소까지 푼 C도 재 볼 수 있다. 무작위 세계의 C는 남쪽 좌회전 손해가 커서 하지 않는다.

**시연.** 저장한 신경망과 입력 계산만으로 SUMO GUI를 맥에서 돌린다. 계획기 코드를 불러오지 않는 실행 파일로 만들고, 같은 상황을 평가 경로와 대조해 신호가 같음을 확인한다.

- 흉내 값과 강화학습 몫을 나눠 적는다.
- 세계를 섞지 않는다. 무작위 세계, 무리 세계(모형), 12개 지도를 따로 적는다. 단독 지도의 구간 %와 도로망 %를 나란히 놓지 않는다.
- 몫을 더하지 않는다. 규칙 B +1.4초와 t20 +0.97초를 합쳐 말하지 않는다.
- 12판 값은 '12판 점검, 판정 아님'이라고 적는다.
- RELAX0 D의 −40%대는 현실에 없는 규칙의 상한이다. 모델 성과로 쓰지 않는다.
- 'DQN의 한계' 대신 '시험한 설정의 성능 정체'라고 쓴다.
