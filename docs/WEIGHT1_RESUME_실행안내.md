# WEIGHT1 충돌 진단·재개용 Colab

현재 긴 학습은 seed42 333회,43 292회,44 294회에서 저장돼 있다. 목표는 기존과 같은 각417회다. 제어 시작 전 준비 구간 충돌이 발견돼 중단됐으며, 원본의 시간 부족 안내는 실행기 분류 오류다. 원본 학습과 결과를 보존하고 새 버전에서 진단·검토 후 이어갈 수 있게 준비한다.

## 지금 할 일

1. Drive `MyDrive/FutureTraffic`의 `WEIGHT1_Resume_Colab.ipynb`를 Colab으로 연다. 같은 폴더에 `FutureTraffic_WEIGHT1_Resume.zip`이 동기화돼 있어야 한다.
2. 위에서부터 **모두 실행**한다. 기존 결과 폴더를 지우거나 이름을 바꾸지 않는다. CPU2개 이상이면 되고 GPU는 필수가 아니다.
3. 먼저 충돌이 난 준비 구간만 재현해 차량 궤적과 지도 연결을 저장한다. **진단 검토 대기**라고 나오면 정상이다. `explore_weight_resume_v1`에 저장된 보고서를 확인한 뒤에야 학습 재개가 가능하다. 단순 재현 성공이 자동 예외 승인은 아니다.

진단을 마치면 이 대화에 “진단 끝났어”라고 알려주면 된다. 보고서는 Drive에 남아 있어 파일을 다시 붙일 필요는 없다. 검토가 끝나지 않은 상태에서 여러 번 실행해 충돌을 무시하려 하지 않는다.

## 검토가 끝난 뒤

차량 궤적·차로 형상·양보 관계·접촉 모양으로 원인을 확인한 경우에만 좁은 판정 근거를 새 실험 지문에 묶는다. 현재 확인하지 못한 충돌을 임의로 무시하거나 실패 에피소드를 생략하지 않는다. 지도·수요·학습 설정을 바꾸는 수정이 필요하다면 기존 실험의 단순 재개로 처리하지 않고 추가 설계를 검토한다.

검증된 판정 근거가 등록되면 같은 노트북을 다시 모두 실행해 세 모델·경험 저장소·모든 난수 상태를 별도 복사한 뒤 저장 지점부터 이어 학습한다. 원본 폴더에는 쓰지 않는다. 각417회라는 최종 목표와 관측·보상·알고리즘·탐험 일정은 유지한다. 중간 최고 모델을 최종 모델로 고르지 않는다.

새 충돌 판정 버전에서는 P0·M4 개발 비교도 각각16회 새로 수행한다. 원래 고정 비교 캐시는 재사용하지 않는다. 모든 RL 관찰 시점과 확인 평가도 새 판정 버전으로 수행한다. 성공 문턱은 기존 긴 학습의 개발/확인 기준을 유지한다. 도로·차량 생성·물리·모델 내부 지문은 동일성 검증을 위해 원본과 연결하고 새 외부 지문으로 판정 버전과 계보를 구분한다.
