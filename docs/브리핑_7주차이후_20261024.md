## 0. 한눈에 (결론부터)

1. **공식 결과를 확정했다(10-19).** 시험 4일에서 DQN은 보정 고정신호보다 차 한 대 지연을 석천사거리만 볼 때 **12.6%**, 주변 12개 교차로와 함께 볼 때 **5.1%** 줄였다. 다만 좌회전 차는 더 기다리고, 학습 없는 단순 규칙은 넘지 못했다.
2. **처음 보는 12일로 추가 시험을 했다(10-21).** 더 멀리 내다보게 학습한 DQN(H1)은 보정 고정신호보다 **16.0%** 짧았다. 단순 규칙과는 거의 같은 수준이다.
3. **시험한 DQN 설정들의 성능 정체를 확인했다(10-19~23).** 학습 없이 단순 제어와 같은 정보(차가 어느 방향으로 갈지 포함)로 2분 앞을 계산하는 **예측 제어(P0)**가 모든 DQN보다 짧았다. DQN에게 P0를 흉내 내게 하면 P0에 가까운 38.57초(P0 37.50초)까지 갔다. P0를 더 멀리 보게 하거나, 앞으로 올 차를 정확히 알려 줘도 더 줄지 않았다. DQN 일반이 안 된다는 증명이 아니라, 이 환경에서 시험한 설정들이 강한 비교 제어에 못 미쳤다는 관찰이다.
4. **강화학습 중심으로 방향을 정했다(10-23).** 정보를 더한 DQN(MOV), 고를 수 있을 때만 묻는 DQN(CHO)도 기존과 차이가 없었다. 그래서 'SUMO 안에서 후보를 직접 굴려 보는 탐색'으로 더 좋은 행동 경험을 만들고, 작은 신경망이 그것을 배우게 하는 **탐색과 학습을 결합하는 방향**을 채택했다. 이후 배운 신경망을 후속 탐색에 사용해 학생을 한 번 학습하는 PI1을 실행했으나 성능 개선은 확인하지 못했다(2.9).
5. **탐색 제어가 제한된 비교에서 처음으로 P0를 이겼다(10-24).** 1시간 연속 제어에서 6쌍 모두 P0보다 나았다(평균 **1.19초**, 2.9%). 이득은 오래된 약점인 길주로 동쪽 좌회전에서 나왔다. 학습된 신경망이 아니라 탐색기 자체의 결과다.
6. **그 이득을 작은 신경망에 옮기는 일은 아직 성공하지 못했다(10-24).** 검사를 다섯 번 했다.
   - 학생은 바꿀 시점과 바꿀 녹색을 모두 자주 틀린다.
   - '탐색 점수가 흔들려서'라는 설명은 약해졌다(큰 손해 10곳을 새 시나리오로 다시 재도 평균이 원래의 약 74%로 남음).
   - 새 날짜 3개(탐색 85번)를 더해 학습 묶음을 3개에서 6개로 늘려도, 학습에 쓰지 않은 날짜의 연속 제어에서 **개선을 확인하지 못했다**(S6가 S3보다 줄인 지연, 즉 S3 지연 − S6 지연: −0.31초, 95% 구간 [−1.09, +0.48]). 학생 셋 모두 P0를 넘지 못했다. 미리 정한 대로 추가 수집은 멈췄다(2.7).
   - 탐색기 자체의 이득은 새 날짜 3곳 중 2곳에서 다시 나타났다(+2.95·+2.61초). 남은 문제는 같다. **탐색은 좋은 선택을 찾지만, 신경망은 그것을 다른 상황에 옮겨 쓰지 못한다.**
7. **'관측 정보 × 학습 방법'의 작은 4조합 비교도 개선을 확인하지 못했다.** 관측 2가지(기존 / 이동 방향별 차량 위치를 시간 구간으로 요약한 정보 추가) × 학습 방법 2가지(탐색 비용 회귀 / 같은 비용표로 좋은 선택의 확률을 직접 높이는 정책 최적화)를 같은 자료·같은 평가로 비교한다(2.8, 계획 148절). 'DQN 대 정책 기반 강화학습'의 비교가 아니라, 탐색 기반 정책 학습 안에서 두 학습 방법을 비교하는 것이다(150·151절). 비싼 탐색은 다시 하지 않았다. **결과(10-24 저녁, 153절): 이 4조합으로는 개선을 확인하지 못했다.** 기준보다 나아졌다고 판정된 칸이 없고, 네 칸 모두 P0를 넘지 못했다(가장 가까운 B도 −0.19초). 직접 정책 최적화는 동쪽 좌회전 지연을 남쪽 좌회전으로 옮겼을 뿐이다(2.8·3.6).

8. **현재 정책의 미래 비용으로 한 번 개선하는 PI1을 실행했지만 개선은 확인하지 못했다(10-25).** 최근 수요 29칸은 미채택했고, 부모가 방문한 상태 48개에서 독립 미래의 개선 가능성 기준은 통과했다. 그 비용으로 학생을 한 번 학습했으나 실제 지연은 부모 39.49 → 학생 39.89초였고 P0 39.30초도 넘지 못했다. 이전의 ‘반복 시도 전’에서 ‘첫 반복 실행, 개선 미확인’으로 상태가 바뀌었다(2.9·3.7).

9. **H1을 학습량만 3배(10만 → 30만 단계)로 늘려도 검증 지연이 문턱 넘게 줄지 않았다(10-25, 162~164절).** 평가에 쓴 최종 H1 모델에서 이어 학습했고, 관측·보상·설정은 그대로다. 검증 2일 지연은 39.78 → 39.71 → 39.26초로 '차이 없음'(문턱 1.3초)이며, 평균 개선의 대부분은 seed 하나에서 왔다. 단순 제어와는 차이 없고 P0에는 못 미친다. 그래서 '학습을 더 오래 하면 나아질 것'이라는 설명은 이 설정에서 확인되지 않았다(중간 모델을 따로 평가해 확인). DQN 일반의 한계는 아니며 개발 평가다.

## 0.5 이번 기간의 중심 서사와 중심 문장 (143절 검토 반영)

- **큰 목표는 그대로다**: 강화학습 기반 교통신호 최적화. 달라진 것은 좋은 정책을 배우는 방법이다.
  - 이전: DQN이 시행착오로 좋은 신호 운영법을 스스로 찾게 했다.
  - 현재: SUMO 탐색으로 더 좋은 선택을 찾아 학습 경험을 만들고, 신경망이 그것을 배우게 한다.
- **흐름(연구노트·보고서 공통)**
  1. 기존 성과: DQN은 고정신호보다 지연을 줄였다(공식 결과, 3.1·3.2).
  2. 발견한 정체: 시험한 DQN 설정들은 단순 규칙이나 예측 제어를 안정적으로 넘지 못했고, 여러 개선 실험으로도 격차를 줄이지 못했다(2.3·2.4).
  3. 접근 확장: 더 좋은 행동 경험을 직접 만드는 SUMO 탐색을 정책 학습에 도입했다(2.4).
  4. 현재 성과와 과제: 탐색 제어는 제한된 비교에서 P0보다 평균 1.19초 나았다(3.4). 그 이득을 신경망으로 옮기는 데는 아직 성공하지 못했고, 새 날짜 경험을 더해도 개선을 확인하지 못했다(2.6·2.7). 남은 과제는 탐색의 이득을 학습 정책의 전체 지연 개선으로 옮기는 일이다. PI1은 배운 장면의 선택을 거의 맞혔으나 연속 제어의 개선은 확인하지 못했다. 이를 일반화 하나의 원인으로 확정하지 않는다.
- **한 문장 흐름(147절 검토)**: "DQN의 성능 정체를 계기로 탐색 기반 정책 학습으로 접근을 확장했고, 탐색 제어의 개선은 확인했으나 학습 정책으로의 전이는 미해결이다."
  - 미해결인 것은 '탐색 경험을 비용 예측 학생으로 옮기는 단계'다. 10-25에는 배운 정책을 후속 탐색에 쓴 첫 반복 PI1도 실행했으나 개선을 확인하지 못했다. 반복 강화학습 전체의 불가능을 뜻하지 않는다.
- **문서마다 무게**
  - 연구노트: 방향을 바꾼 근거와 판단 과정이 중심이다.
  - 중간보고서: 기존 공식 DQN 성과를 충분히 보여 주고, 그것이 새 접근의 출발점이라는 연결을 분명히 한다. 방향 변경만 강조해 확보한 성과를 지우지 않는다.
- **섞지 않는 것**
  - 공식 결과(시험 4일·새 12일)와 추가 탐색(검증 2일)·탐색 제어 예비 결과(학습 날짜 6쌍)를 한 평가 표에 섞지 않는다.
  - P0를 넘은 것은 탐색 제어다. 학습된 학생의 성과로 쓰지 않는다.
- **추천 중심 문장**: "DQN 기반 제어의 성과와 성능 정체를 확인하고, SUMO 탐색으로 더 나은 행동 경험을 생성하여 이를 학습하는 신호 제어 방식으로 연구 접근을 확장하였다."
- 제목을 조정한다면(교수님과 상의): '시뮬레이션 탐색을 활용한 강화학습 기반 교통신호 제어 정책 개선 연구'

## 2. 주제별 정리

### 2.1 공식 결과 확정 (10-15 ~ 10-19)

- **v6 재학습**: 전환 안전 규칙 3가지(없음·1초 기준·1.5초 기준) × seed 5개 = DQN 15개를 다시 학습했다. 주 결과는 1초 기준(pet1)이다. 검증 2일에서 DQN은 보정 고정신호보다 10.7% 짧았고, 전환 4만 3천 번 중 두 차가 겹친 경우는 0번이었다.
- **12개 지도 정비**

## 5. 한계(보고서 한계 절 후보)

- 모든 결과는 AI Hub 교통량을 넣은 SUMO 시뮬레이션이다. 실제 도로 성능을 말하지 않는다.
- 공식 DQN은 좌회전 차를 30~43초 더 기다리게 하고, 학습 없는 단순 규칙을 넘지 못했다. 이 성능 정체는 이 환경에서 시험한 DQN 설정들에 대한 관찰이고, DQN 일반의 한계를 증명한 것이 아니다.
- 12개 지도의 이득은 흔들림과 비슷한 크기다. 배경 교통은 80%로 줄였다(100%면 일부 날짜가 교착). 차로 고침의 근거는 2025-12 로드뷰다.
- 데이터 19일과 새 12일을 모두 썼다. 그 뒤 실험은 공식 결과를 바꾸지 못하고 '추가 탐색'으로만 보고한다.
- 예측 제어·탐색 제어는 차의 경로(방향)를 안다고 가정한다. 실제 감지기로는 공유 차로에서 알기 어렵다.
- 탐색 제어의 최초 이득은 좌회전 정체가 많은 한낮·저녁 1시간, 학습 날짜 6쌍에서 쟀고 구간이 0에 걸친다. 추가 학습 날짜 3개(seed 하나씩)에서는 두 곳의 개선과 한 곳의 소폭 손해를 확인했다(2.7). 새 시험 날짜 일반화의 증거로 쓰지 않는다.
- 학생 검사 ①~⑤는 같은 229개 자료를 여러 번 본 탐색적 증거다. 새 날짜 평가도 '학습 제외 개발 평가'이지 최종 시험이 아니다.
- 새 날짜 평가 16개는 4개 날짜·시간 묶음(날짜 2개)의 seed 반복이다. 같은 묶음의 seed끼리는 수요가 같아 서로 독립이 아니다.
- 확인 안 된 충돌이 석천사거리 밖에서 몇 건 있었다. 재현한 것은 모두 지도 모양이나 정체 속 꼬리물기였고, 신호 전환과는 무관했다.

  - 8주차는 중간고사 주였다(면담 없음). 8주차 노트가 필요한지는 10-15 면담 때 여쭐 목록에 있었지만 답을 확인하지 못했다.

## 7. 중간보고서 구성 제안

1. 연구 목표와 범위: 변함없다. DQN은 석천사거리 신호 하나만 바꾸고, 수요·운전자·주변 신호는 고정한다.
2. 실험 환경: v6(전환 안전 규칙), 단독 모형과 12개 교차로 지도, 공정한 비교 원칙(날짜 분할, 지문, 같은 안전 규칙, 같은 횟수 채점)
3. 주 결과: 시험 4일(3.1)과 처음 보는 12일 추가 시험(3.2)
4. 분석: 시험한 DQN 설정의 성능 정체와 그 단서. 예측 제어는 '단순 제어와 같은 정보로 계산만 한 강한 비교 기준'으로 싣는다(3.3).
5. 후반부 방향: 탐색으로 행동 경험을 만들고 신경망이 배우는 방식. 제한된 탐색 제어는 P0보다 나았고(3.4), 신경망으로 옮기는 일은 아직 풀리지 않았다(2.6). 새 날짜 경험을 더해도(2.7·3.5), 관측 정보와 학습 방법을 바꿔도(2.8·3.6) 개선을 확인하지 못했다.
   - 흐름: 공식 DQN 성과 → 성능 정체 → 탐색 기반 정책 학습으로 접근 확장 → 탐색 제어 개선 확인 → 정책 학습·일반화가 남은 병목.
   - 보고서는 후속 실험 결과를 기다리지 않고 쓴다(147절). 4조합 결과(153절)와 PI1 결과(158절)는 추가 개발 평가로 넣고 공식 결과와 구분한다. PI1은 첫 반복 실행과 개선 미확인까지 적으며 원인은 확정하지 않는다.
6. 한계와 남은 일정
- 확인할 일정: 중간보고서 제출일은 10-27(화)로 적혀 있지만, 10-15 녹취에서는 '26일'로 들렸다(확인 필요). 다음 면담은 10-29다.
