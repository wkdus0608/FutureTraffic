# 현재 현황 — 석천사거리 강화학습 신호 제어

> 갱신: 2026-10-25. 근거: 진행 기록 146~164절과 저장된 결과. H1 이어 학습(30만 단계)도 차이 없음으로 끝났다(164절). 한 차례 정책 개선 PI1까지 완료했으나 부모 대비 개선과 P0 초과를 확인하지 못했다. 자동 추가 수집·두 번째 라운드는 없다. 이 문서는 현재 상태의 진입점이고 판단 이력은 [진행 기록](../PROJECT_PROGRESS.md)에 보존한다.

## 목표와 연구 접근

**강화학습으로 학습한 정책이 강한 비교 제어보다 좋은 신호 운영을 하도록 만드는 것**이 목표다. 수요·운전자·운영 규칙을 같게 두고 신호만 바꾼다. 석천사거리 하나를 제어하며, 12개 교차로 지도에서도 주변 11곳의 신호는 고정된 실제 시간표를 따른다.

DQN은 고정신호보다 개선했지만 시험한 설정들에서 단순 규칙·예측 제어 P0와의 격차가 남았다. 이에 SUMO에서 후보 행동을 직접 비교해 더 좋은 경험을 만들고 신경망이 배우도록 접근을 확장했다. **탐색 제어의 개선은 확인했으나 학습 정책으로의 전이는 미해결**이다. DQN 일반의 불가능성이나 신경망·정보의 무관함을 증명한 결과는 아니다.

## 최근 완료: 관측 정보 × 학습 방법(COMBO) — 개선 미확인

| | 비용 회귀 L0 | 직접 정책 최적화 L1 |
|---|---|---|
| 기존 72칸 O0 | A: S6 가중치 그대로 | C |
| 위치 분포 24칸 추가 O1(96칸) | B | D |

### 바꾸는 두 요소

- **관측:** 현재 감지 구간에서 움직이는 차를 이동 8개별로 세 시간 구간에 센다. 시간은 정지선까지 거리÷도로 제한속도이며 구간은 [0, 10), [10, 20), [20초 이상)이다. 차 수÷20, 최대 1로 만든다. 이는 이동별 차량 위치의 요약이며 실제 도착 시각의 예측이 아니다.
- **학습:** L0는 저장된 후보별 상대 비용을 맞혀 최소 후보를 고른다. L1은 같은 추정 비용표를 이용해 선택 확률의 기대 비용을 직접 줄인다. **DQN 대 정책 기반 강화학습의 비교가 아니다.** 실제 장기 지연의 정확한 정책 경사를 구한 것도 아니다.

기존 72칸에도 밀도·전체 차량 수가 있다. 추가되는 것은 이동별·거리별 분포다. 실제 미래 출발 차는 입력에 넣지 않으며 현재 차량의 회전 의도를 경로로 안다는 가정은 남는다.

### 공통 조건과 판정

- 같은 314개 학습 장면·같은 후보 비용을 사용한다. 기존·신규 장면 모두에 새 관측을 만들며 후보별 600초 탐색은 다시 하지 않는다.
- 학생은 입력 72/96 → 32 → 32 → 4의 MLP, 10,000회 갱신, 시작값 5개 모델의 예측 평균을 쓴다.
- 같은 16개 조건에서 P0·A·B·C·D를 연속 제어해 총 80회를 평가한다. 좌회전 정체 시점에서만 학생이 선택하므로 **P0+신경망 혼합 제어**다.
- **A보다 개선됐는가**와 **P0를 넘었는가**를 별도로 판정하고, 관측 효과·학습 효과·상호작용을 함께 본다.
- 사전 주 판정은 바꾸지 않는다. 묶음 4개의 평균과 그 평균으로 계산한 구간도 함께 보고한다. 결론은 개발 평가의 단서다.
- 결과를 보고 조합·스케일·학습 설정을 늘리지 않는다. 미통과가 관측이나 학습 방법 일반의 무효를 뜻하지도 않는다.

### 실행과 확인

완료한 COMBO의 실행 이력은 노트북 **1~3번 칸 → 41번 칸**이었다. 재실행 지시가 아니다. 9개 기록 재생 → 관측 만들기 → 학습 → 평가 → 참고 저장 장면 평가 → 요약을 실행한다. 예산은 계획상 30~40분이다.

314개 모두에 관측이 붙어야 한다. 재생은 마지막 탐색 시점(08-19의 5401초 포함)까지 기록과 일치해야 하며 다르면 멈춘다. P0와 A의 새 결과는 이전 P0·S6 결과와도 대조한다. 완료 파일을 재사용하는 구조이므로 코드를 바꾼 재실행은 새 출력 경로를 쓴다.

## 최신 완료: 한 차례 정책 개선(PI1) — 개선 미확인

**10-25 결과: 정책 개선 미확인.** 수요 이력 29칸은 사전 기준을 통과하지 못해 96칸 부모(B)를 유지했다. 부모가 방문한 학습 상태 48개에서 후보를 비교했고, 독립 확인 미래의 이득 합 +2,241대·초·3묶음 중 2개 양수·22개 선택 변경으로 학생 한 번 학습 기준을 통과했다. 그러나 실제 연속 제어에서는 그 이득을 유지하지 못했다.

| 정책 | 평균 차량 지연 | 부모보다 줄인 지연 | P0보다 줄인 지연 |
|---|---:|---:|---:|
| P0 | 39.30초 | — | — |
| 부모 B | 39.49초 | 기준 | −0.19초 |
| PI1 학생 | 39.89초 | **−0.40초** | **−0.59초** |

부모 대비 줄인 지연의 4묶음 95% 구간은 [−1.37, +0.57]초, 개선 묶음은 1/4다. 개선을 확인하지 못했으며 일반적인 악화가 확정된 것은 아니다. 동쪽 좌회전은 117.73 → 112.72초로 줄었지만 남쪽은 98.59 → 105.04초로 늘어, 부모 대비 5초 이내 조건도 통과하지 못했다. 네 수요 조건의 seed 반복을 다시 쓴 개발 평가이며 새 날짜 최종 시험이 아니다.

누적 비용은 **33,070.86 CPU초 / 상한 36,000초**다. 요약의 평가 48개에서 누락·미완료·규칙 개입·충돌·300초 초과는 모두 0이다. 원시 평가 48개가 요약과 같고 P0·부모의 기존 32개 결과도 재현됐다. 코드 지문·모델 10개 해시·실험 지문·CPU 장부 대조를 통과했다. 결과는 `results/explore/policy_iter_20261025/`이며 근거는 진행 기록 156~158절이다. **자동 추가 수집·두 번째 라운드는 시작하지 않는다.**

### 이번에 달라진 연구 상태

- 이전의 ‘배운 정책으로 다시 탐색하는 반복은 아직 시도 전’에서 **한 번 실행했으나 성능 개선 미확인**으로 바뀌었다.
- 125칸 최근 예정 수요 요약은 제외 묶음 점수에서 96칸 −21,242대·초보다 낮은 −32,162대·초, 개선 묶음 2/6으로 미채택했다. 이 요약 설계의 개발 진단이지 최근 수요 정보 일반의 무효가 아니다.
- P0 후속 운영과 부모 후속 운영의 최소 비용 후보는 48개 중 19개에서 달랐다. 후속 정책을 바꾸는 것이 선택에 영향을 주었지만, 실제 제어 개선의 증거는 아니다.
- 선택용 미래의 예상 이득 합은 28,427대·초였으나 독립 확인에서는 2,241대·초로 줄었다. 바꾼 22곳 중 확인 이득은 12곳, 손해는 10곳이다. 작은 가능성 기준은 통과했지만, 학생이 배울 후보의 이득이 안정적이라는 근거는 아직 약하다. 이 차이를 잡음 비율로 해석하지 않는다.
- 판정 뒤 추가 학습 없이 고정 가중치로 검사한 결과, 새 학생은 학습 장면 48개 중 탐색 선택과 47개가 같았고 선택용 미래의 예상 이득 99.86%를 회수했다. 배운 장면을 맞히는 것은 확인했으나 실제 연속 제어 개선은 아니며, 실패 원인을 일반화 하나로 확정하지 않는다. 자료·관측·학습·목표 비용·유한 탐색이 섞여 있다.
- **현재 새 Colab 실행은 없다.** 37~42번 칸은 완료했으며 결과를 보존하고 후속 방향을 판단한다. 코드·노트북과 사전 기준은 [PI1 안내](정책개선_PI1_실행안내_20261024.md)에 남긴다.

- 평가에 쓴 최종 H1 모델 5개에서 출발해 학습량만 30만 단계까지 늘렸다(관측·보상·도착 생성·설정 그대로, 진행 기록 162~164절, Colab 43번 칸).
- 실행 확인은 모두 통과했다(출발 모델 지문, 경험 저장소 경계 표시, 탐험률 0.05, 다시 시작 0번, 10만 시점 재현 10/10).
- 검증 2일 차량당 지연: 10만 39.78 → 20만 39.71 → 30만 39.26초. **주 판정(30만 대 10만, 문턱 1.3초): 차이 없음 — 이 설정에서 추가 20만 단계의 효과를 확인하지 못했다.**
  - 평균 개선 0.52초의 대부분은 seed 하나(seed 45, +2.64초)에서 왔다. seed 45를 빼면 30만이 약 0.014초 더 길어 사실상 같다. seed마다 오르내림도 크다.
  - 세 시점 모두 단순 제어(39.69초)와 차이 없고, P0(37.50초)에는 못 미친다. 보정 고정신호보다는 15.9~17.0% 짧다.
  - 길주로 동쪽 좌회전은 136.2 → 113.6초로 줄었지만 전체 지연은 거의 같았다(판정 밖 관찰).
- 확인 안 된 충돌 1건(30만 seed 45, 09-28, 서쪽 분기점, 석천사거리 밖): 과거 고정신호에서 원인을 확인한 것과 같은 모양이지만 재현하지 않았다. 판정은 그 실행을 빼도 같다.
- 뜻: H1 설정에서는 경험을 3배로 늘려도 검증 지연이 문턱 넘게 줄지 않았다. DQN 일반이나 다른 설정의 한계를 뜻하지 않는다. 개발 평가이며 공식 결과는 바뀌지 않는다. 결과: `results/explore/h1long_20261025/`.

## 보고서에 사용하는 설명

**DQN의 성과와 성능 정체를 확인하고 탐색 기반 정책 학습으로 접근을 확장했다. 탐색 제어의 개선은 확인했으나 학습 정책으로의 전이는 미해결이며, 관측 정보와 학습 방법을 바꾼 네 조합 및 현재 정책의 미래 비용을 이용한 한 차례 개선에서도 학습 정책의 전체 지연 개선을 확인하지 못했다.**

기존 공식 성과, 조건이 제한된 탐색기의 예비 성과, 아직 확인되지 않은 학생의 성과를 구분한다. 과거의 계획·진단은 날짜가 붙은 문서에 남기고 현재 실행 판단은 이 문서와 진행 기록을 따른다.
