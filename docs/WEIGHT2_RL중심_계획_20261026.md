# WEIGHT2 계획: M4에서 출발해 추가 이득을 배우는 강화학습

2026-10-26. 사용자가 강화학습을 프로젝트의 필수 조건으로 재확인했다. 이 문서는 다음 실험의 제안이며, 구현·학습·시뮬레이션을 시작했다는 뜻이 아니다. 실행은 사용자가 Colab에서 하고 맥은 준비·분석에만 사용한다.

## 1. 현재 상황과 목표

같은 WEIGHT1 개발 평가의 평균 차량 지연은 원래 P0 39.429076초, 고정 M4 38.490670초, 학습 정책 38.964073초다. 학습 정책은 P0보다 낮았지만 고정 M4보다0.473403초 높아 사전 확대 기준을 통과하지 못했다. 고정 M4의0.938406초 이득은 수동 가중치 조정의 개발 평가 단서이며 강화학습 성과로 세지 않는다.

모드가 서로 다른 신호를 제안한266번 중189번(71.05%)에는 RL이 P0와 다른 신호를 선택했다. 대부분 시점은 모든 모드가 같은 신호를 내므로 전체 M0 비율98.4%로 원인을 단정하지 않는다. M4보다 느린 원인도 특정하지 않았다.

**최종 목표는 실제 지연 보상으로 학습한 제어기가 P0와 고정 M4를 모두 개선하는 것이다.** P0 계획기를 실행 중 함께 쓰는 결합 강화학습이다. M4만 검증한 결과로 RL 목표를 대체하지 않는다.

## 2. 새 학습 설계

- 같은5개 가중치 모드·110칸 관측·120초 계획·5초 판단·운영 규칙·실제 지연 보상을 유지한다. 가중치2.5/3.0 등 수동 후보는 추가하지 않는다.
- 기본 행동은 그 상태에서 M4가 제안하는 신호다. 같은 신호의 대표 모드 번호를 찾고, 후보 가치가 동점이면 그 대표를 우선한다. 모드4를 무조건 허용하거나 기존 마스크를 무시하지 않는다.
- 가치망을 공통 지연 예측과 M4 대비 후보 차이로 나눈다. 내부 식은 `Q(s,m)=V(s)+A(s,m)-A(s,b(s))`이며 `b(s)`는 M4 행동의 대표 모드다. A 출력층을0으로 초기화하면 탐험 없는 초기 동작은 정확히 M4다. V와 A는 이후 실제 전이로 함께 TD 학습한다.
- 기존11개 학습 날짜 각각13시·18시의 M4 실행22개를 초기 가치 학습에 사용한다. 개발/확인 날짜는 넣지 않는다. 같은 시간 손실·진입 대기 정산과900초 후속 비용을 사용해 할인 반환을 만든다. V는64–64, Adam0.001·Huber·batch256·20epoch·난수20261026으로 학습하고 마지막 가중치를 고정 초기값으로 저장한다. 이 자료는 초기V 학습용이며 제어 TD 저장소는 새 RL 전이부터 채운다.
- 신경망은64–64의 공통 몸통과 V/A 출력층, Double DQN·n-step10·gamma0.99를 유지한다. 나머지 학습 설정은 WEIGHT1을 유지한다. 탐험은 제어 단계에서 허용 대표 모드 안의 epsilon0.2로 고정하고 평가는0으로 한다. 초기평가의 M4 재현과 탐험 중 동작을 구분한다. 영구 모방 벌점·개입 벌점·P0 모형 오차 보상은 넣지 않는다.
- 초기 가치 학습과 탐험을 포함한 새 설계 전체를 WEIGHT2로 구분한다. WEIGHT1의 학습량만 늘린 실험, 또는 초기화 한 요소만의 인과 비교로 부르지 않는다. 실제 선택이 악화될 가능성도 있으므로 개선은 연속 제어로 판정한다.

## 3. 실행 순서와 확대 조건

1. **초기 동등성 검사:** 탐험0·A=0에서 M4와 모든 첫 행동·총 지연이 같은지 확인한다. 모드/현시 저장과 마스크·비용 정산·재개 검사도 통과해야 한다.
2. **첫 예비 학습:** seed42로42에피소드(30,240 제어 단계)를 학습한다. 기존 개발4조건×평가seed42~45에서 P0·고정M4와 비교한다. 평균이 두 비교 대상보다 짧고 각 비교에서4조건 중3조건 이상 개선돼야 다음으로 간다. 좌회전 각+5초 이내·장기 대기 비율 비증가·완전성·안전 조건도 적용한다. M4 초기자료22개와 이 첫 단계의 새 계산 상한은4시간이며, 이미 쓴 WEIGHT1 예비6시간 한도를 사후 변경한 것으로 해석하지 않는다.
3. **재현 확인:** 첫 모델 통과 시 같은 설정으로 seed43·44의42에피소드 모델을 만든다. 세 모델의 평균 개선이 P0/M4 모두에 양수이고2/3모델 이상 개선, 합산 개발조건3/4 이상 개선, 보조 조건도 통과해야 본학습으로 간다. 초기자료를 포함한 새 예비 단계 합산 상한은9시간이다.
4. **본학습:** 예산에 전체가 들어갈 때만 같은3개 모델을139에피소드(100,080단계)까지 이어 학습한다. 마지막 모델만 사용하며 잘 나온 seed나 중간 체크포인트를 고르지 않는다. 이번 새 실험은 최종3개 학습 난수로 고정해 총예산을 지킨다.
5. **확인 평가:** 모든 설정과3개 모델을 잠근 뒤 P0·고정M4·학습3개를 한 번에 비교한다. 09-28·08-13×07:30·12:30·17:30·21:30×평가seed1042~1049, 정책5개로320회다. M4만 먼저 이 조건에서 재고 그 결과로 다시 설계를 고르지 않는다.

고정 M4는 기존 개발 평가에서 선택한2.0 그대로 유지한다. 이번 확인 조건도 과거에 사용한 날짜이므로 추가 개발 확인 평가이며 새 날짜/실제 도로 일반화가 아니다.

## 4. 성공 기준과 예산

확인 평가의 두 비교(P0 대비, M4 대비)를 모두 통과해야 한다.

- 차량 수 가중 평균 지연 감소.
- 고정8개 수요 조건에서 학습 난수3개와 평가 난수8개를 독립 재표집한10,000회95%구간 하한>0. 재표집seed20261026. 세 학습 난수라는 작은 표본의 한계를 함께 보고한다.
- 학습3개 모두 평균 개선, 날짜·시간대8조건 중6조건 이상 개선.
- 같은 조건 전체를 합산할 때 두 좌회전 지연은 각 기준보다5초 넘게 늘지 않고,300초 초과 대기 비율도 늘지 않음.
- 누락·미완료·실행 규칙 오류가 없고 미확인 충돌이 없어야 함. 정상 강제 판단과 실제 행동 오류를 구분함.

학습 전 M4와 같은 성능을 RL의 개선으로 세지 않는다. 학습 후 고정 M4 대비 추가 이득이 성과다. 개발 예비 단계 미통과 시 이 설계의 본학습은 확대하지 않으며, 기존 WEIGHT1 결과를 성공으로 재분류하지 않는다.

전체 계산 한도48시간은 유지한다. Colab WEIGHT1 18,000.48초와 취소된 맥 실행 장부3,059.53초를 합산하면 이미 약5.85시간을 썼고 약42.15시간이 남는다. 초기자료 수집·가치 학습·TD 학습·평가·실패·저장 시간을 모두 계산한다. 과거 Colab 실측으로 새 설계는 약29시간 규모,25% 여유 포함 약36시간으로 추산되나 실행환경에 따라 달라진다. 첫 예비 단계 실측으로 잔여 전체 비용을 다시 계산하고, 남은 총예산에 들어가지 않으면 확대를 보류한다. 결과를 보고 조건이나 seed 수를 줄이지 않는다.

## 5. 근거와 해석 범위

기존 제어기와 RL 보정을 결합하는 구조의 연구 사례는 [Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201)에 있다. 그 논문은 로봇 연속 제어이며, 이 이산 모드 설계와 같은 구현이나 성능 보장을 뜻하지 않는다. 여기서는 명확한 초기 동작, 실제 지연 TD 학습, 고정 M4보다 추가로 개선됐는지의 비교가 핵심이다.

가치와 상대 우위의 재매개변수화는 실제 보상을 임의의 행동 의존 모형 오차로 바꾸는 것과 구분한다. 보상 변경의 정책 보존에는 조건이 필요하다([Ng·Harada·Russell, 1999](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)). 본 설계는 실제 지연 보상을 유지한다.

구현·Colab 묶음·실행은 아직 시작하지 않았다. 맥 실행 취소는 유지한다.

## 추가 검토: 기존 모드 RL의 학습량 확인

사용자의 학습량 질문을 반영한176절 권고 보정이다. WEIGHT2가 최고 성공 확률의 방식으로 입증된 것은 아니다. 새 구조 구현 전에 현재 WEIGHT1을 같은 설정으로42→84→139에피소드에서 비교하는 별도 학습량 검사를 먼저 검토한다.84는 진단,139는 사전 고정 주 비교다. 이 순서 변경 제안은 실행 승인이 아니며 기존pilot미통과를 바꾸지 않는다. 학습량 검사 없이 WEIGHT2가 반드시 더 낫다고 주장하지 않는다.
