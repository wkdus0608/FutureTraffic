# 개선 방향 재검토: 강한 계획 제어 위에서 실제 비용을 학습하기

2026-10-25. 진행 기록 166절의 설계 검토 문서다. 새 제어기의 구현·학습 결과나 사용자의 채택 결정은 아니다. 목표는 강화학습이 기여하는 제어로 P0를 넘는 것이다. 기존 공식 결과와 평가 분할은 보존한다.

## 1. 이전 권고에서 바로잡을 점

실패 원인을 특정하지 못한 상태에서 정보 추가·결정 시점 압축·자료 확대·학습량 확대를 차례로 제안했다. 이들은 처방의 효과를 검사했지만, 목표 성능을 높일 수 있는 설계를 확보한 것은 아니었다. 실패를 이유로 원래 목표를 고정신호 대비 성과로만 바꾸는 것도 사용자의 개선 요구에 충분한 답이 아니다.

| 근거 | 확인한 것 | 확인하지 못한 것 |
|---|---|---|
| H1 10만→30만 | 같은 설정에서 사전 기준의 일관된 전체 지연 개선 미확인 | 더 적합한 관측·목표·학습 구조의 가능성 |
| MOV·CHO | 특정 8칸 추가와 강제 구간 압축의 효과 미확인 | 관측과 행동 설계 일반이 충분한지 |
| P0 모방 | 신경망이 P0에 가까운 행동을 낼 수 있음 | 관측·표현 구조·일반화가 모두 충분한지 |
| 모방 후 RL | 시범 25%와 모방 벌점을 끝까지 둔 학습이 추가 개선을 만들지 못함 | 모방 정책에서 출발해 모방 제약을 풀었을 때의 효과 |
| 탐색·학생·PI1 | 제한된 연속 탐색 제어의 예비 개선, 학습 정책의 개선 미확인 | 표본 탐색의 작은 이득이 관측만으로 안정적으로 학습 가능한지 |

모방 벌점은 `src/explore_teacher.py`의 MARGIN=0.8·MARGIN_WEIGHT=1·DEMO_SHARE=0.25와 RL의 `td + MARGIN_WEIGHT*m`에서 확인된다. 이 특징은 107절에도 적혀 있었다. 이번에 처음 발견한 버그나 확정된 실패 원인으로 부르지 않는다. 이미 적힌 반례를 이후의 방향 판단에 충분히 반영하지 못한 것이다.

## 2. 코드에서 확인한 중요한 사실

- 현재 DQN의 보상은 5초 끝의 감지 구간 정지 차량과 진입 대기 수다. 평가는 차량 전체의 timeLoss+departDelay다. 두 목적은 같지 않다. 실제 평가 비용의 증가량으로 학습한 DQN은 이번 계열에서 시험하지 않았다.
- 다만 H1L 저장 평가 30개를 다시 셌을 때 두 값은 함께 줄었다. 전체 평가 지연 39.7777→39.2599초, 정지+진입 대기 적분/차량 수 30.4651→30.0381초다. 이것은 두 정의가 다르다는 사실만으로 보상 불일치를 주원인으로 단정할 수 없다는 단서다. `results/explore/rethink_20261025/objective_alignment.json`에 원시 실행별 집계를 남겼다. 사후 진단이며 새 성능 시험은 아니다.
- 행동 마스킹·실제 실행 행동 저장·Double DQN·n-step 할인 처리에서 이번 검토로 새로운 명백한 오류는 찾지 못했다. 버그가 없다는 증명도, 한 줄 수정으로 해결된다는 근거도 아니다.
- P0는 이동별 큐·신호 제약을 사용해 120초 계획을 직접 비교한다. 기존 학생들은 이 계획 기능을 실행 중 유지하지 않고 작은 관측의 신경망으로 신호 선택을 다시 구현해야 했다. 잘 학습한 장면의 선택을 맞히는 것과 새 상태에서 계획을 대체하는 것은 다르다.

## 3. 우선 검토할 새 설계: P0의 상대 비용 + 강화학습 보정

최종 제어기에 P0와 신경망을 함께 둔다. P0는 허용 현시·최소 녹색·전환 비용·앞으로의 계획을 계속 계산한다. 강화학습은 실제 SUMO 결과를 통해 후보 사이의 예상 비용 차이를 보정한다. 최종 정책이 신경망 단독이어야 한다는 추가 요구가 있으면 이 설계는 맞지 않으며, 그 경우에는 별도의 독립 RL 재설계가 필요하다.

개념 예시(실제 측정값 아님):

| 후보 | P0 예상 비용 | 학습한 보정 | 선택에 쓰는 합 |
|---|---:|---:|---:|
| A | 100 | +20 | 120 |
| B | 105 | +3 | 108 |

이 예시는 P0가 A를 택하던 상태에서 실제 경험을 반영한 합은 B를 택할 수 있음을 설명한다. 매번 두 후보의 진짜 비용을 알고 학습한다는 뜻은 아니다. 실제 실행·탐험으로 관측한 전이와 다음 상태 가치로 학습한다.

실행·학습 구성은 다음과 같다.

1. 각 허용 첫 행동 a에 대해 기존 `explore_pred.plan(..., first_actions=[a])`를 이용해 P0 비용 C0(s,a)를 구한다. 모든 후보의 최솟값과 동점 규칙이 원래 P0와 같은지 먼저 확인한다. 후보별 계산으로 실행 시간이 늘 수 있으므로 측정한다.
2. 신경망의 행동별 보정 출력을 0으로 초기화한다. 공통 가치와 상대 우위를 분리하는 한 가지 예는 `Q(s,a)=V(s)−[C0(s,a)−min_b C0(s,b)]/scale+delta(s,a)`다. V는 행동 공통 값이다. 단위·scale·할인 방식은 학습 전에 정의해야 한다. 이 식은 설계 후보이며 검증된 프로젝트 알고리즘이 아니다.
3. 초기 보정이 0일 때 행동은 원래 P0와 같아야 한다. 이것은 초기화의 성질이며, 초기 P0의 성능을 RL이 만든 개선으로 보고하지 않는다.
4. 보상은 평가 대상 차량에서 해당 5초 동안 증가한 실제 timeLoss와 진입 대기의 음수 합으로 구성한다. 도착한 차량의 마지막 손실·기존 차량의 시작값·시간 경계·미진입 차량을 정확히 처리한다. 합한 보상과 독립 차량별 비용이 맞는지 확인한다. 집계 도구의 정확성과 학습 중 API의 실시간 이용 가능성은 별도로 확인해야 한다.
5. 실제 SUMO 전이에서 다음 상태의 같은 결합 Q로 TD 목표를 갱신한다. 저장된 8개 미래의 최저 후보를 정답으로 외우는 손실과, P0와 다르게 선택했다는 이유만의 영구 벌점은 사용하지 않는 설계다. 단순히 신경망 출력과 P0 비용을 더했다는 것만으로 정책 개선이 보장되지는 않는다.
6. 학습·실행 관측은 실제 제어에서 얻을 수 있는 정보로 동일하게 정의한다. 탐색기만 알던 운전자 난수나 실제 미래 수요를 보정망에 주지 않는다. P0 및 비교 정책과의 정보 차이도 기록한다. 신호·보행 제약은 유지한다.

기존 '계산 결과를 관측에 넣는 DQN'에서는 계산을 무시하거나 계획 자체를 다시 배워야 할 수 있다. 이 설계에서는 P0 비용이 실행 점수에 명시적으로 남는다. 기존 P0 복귀 문턱·행동 분류 학생·PI1과도 다르다. P0보다 나빠지지 않는 보장은 없다.

## 4. 검증할 질문과 보고할 것

우선 하나의 일관된 새 제어기를 만들어 종합 효과를 평가하는 접근이다. 관측 한 칸·학습 횟수 하나씩 끝없이 바꾸는 방식으로 진행하지 않는다. 성공하면 구성 요소를 빼는 비교로 무엇이 기여했는지를 분석한다. 아직 새 학습 예산·단계·채택 문턱을 승인받거나 본실험 계획으로 고정하지 않았다.

- 학습 전: 보정 0의 행동이 P0와 같은가? 전체 비용 집계가 기존 평가와 같은가? 계산 시간이 감당 가능한가?
- 학습 후 핵심: 동일 조건의 P0 단독보다 실제 연속 제어 지연이 줄었는가? 학습 seed별·날짜별로 방향이 유지되는가? 좌회전·300초 초과·충돌 조건은 어떤가?
- 학습 효과 분리: 같은 결합 제어에서 학습 보정을 끈 경우와 켠 경우를 비교한다. P0를 붙인 것만으로 생긴 이득을 RL의 성과로 세지 않는다.
- 저장 장면 점수는 진단으로만 쓰고, 채택은 연속 제어로 판단한다. 개발 평가 날짜를 새 최종 시험으로 부르지 않는다.
- 자동 추가 수집·학습량 확대를 예약하지 않는다. 초기 동등성이나 비용 집계가 틀리면 장시간 학습 전에 고친다.

## 5. 다른 남은 경로의 위치

선생님 모방 모델에서 모방 벌점을 제거하거나 점차 줄인 실제 RL은 아직 배제되지 않은, 비교적 작은 별도 경로다. 다만 그 모델이 P0 자체와 같은 정책은 아니고 자유 학습에서 좋은 정책을 잊을 수도 있다. 이를 이미 실패했다고 처리하지 않되 성공법으로 단정하지 않는다.

독립 신경망 정책을 새로 설계한다면, 이동별 구조·다가오는 차량·최근 흐름을 일관되게 표현하고 실제 비용 증가량으로 학습하는 것이 후보가 된다. 작은 학생에 24칸을 붙인 실험은 이 독립 RL 설계를 시험한 것이 아니다. 현재 증거로 특정 신경망 크기나 PPO가 답이라고 말할 수는 없다.

## 6. 문헌과 적용 한계

- Gros & Zanon, *Data-driven Economic NMPC using Reinforcement Learning*, IEEE TAC 2020: https://arxiv.org/abs/1904.04152 . 모델이 완벽하지 않을 때 예측 제어를 RL로 조정하는 구조의 근거다. 위의 이산 신호·상대 비용 보정 제안이 해당 논문의 구현과 같거나, 이 프로젝트에서 성능 보장을 받는 것은 아니다.
- Cabrejas-Egea 외, *Assessment of Reward Functions for Reinforcement Learning Traffic Signal Control under Real-World Limitations*: https://arxiv.org/abs/2008.11634 . 보상 선택을 현실적 신호 제약 아래 통제 비교한다. 그 논문의 최적 보상을 우리 환경의 답으로 복사하지 않는다.
- Zhang 외, *Expression might be enough*, ICML 2022: https://proceedings.mlr.press/v162/zhang22ah.html . 대기·접근 차량의 교통 이동 표현을 설계하는 근거다. 우리 교차로에서 같은 우위를 보장하지 않는다.

이 검토가 제시하는 것은 기존 실패에서 아직 시험하지 않은 구조적 경로다. 성능을 개선하는 방법이 이미 확보됐다는 주장은 아니다.
