# 석천사거리 DQN 신호제어 실험 결과 (2026-10-03, v3.2)

> 자동 생성 보고서: `results/focused_204820/v3/report.md` (날짜별 표 포함), 진행 기록: `PROJECT_PROGRESS.md` 27절.
> 결론의 범위는 **AI Hub 실제 교통량을 넣은 SUMO 시뮬레이션**이다. 실제 도로 성능이 아니다.

## 1. 질문

학습에 쓰지 않은 날짜에서, 석천사거리(`204820`) 신호를 DQN이 맡으면 기존 고정신호보다 차량 대기와 대기행렬이 줄어드는가?

## 2. 방법

| 항목 | 내용 |
|---|---|
| 교통량 | 석천사거리에서 기록된 회전 1건 = 차량 1대. 이동별 15분 교통량을 그 15분 동안 무작위 시각에 도착시킨다(1분 통과 기록에는 실제 신호의 녹색 시점이 찍혀 있어 그대로 쓰면 실제 신호에 유리해진다). |
| 도로 | 교차로 앞 최대 300m·뒤 최대 150m만 주행. 다른 교차로 차량은 넣지 않는다. |
| 기존 고정신호 | AI Hub 실제 운영 신호. 녹색 이름이 한 현시씩 밀린 것으로 보정해 쓴다. |
| 비교 신호 | 지도에 내장된 신호(참고로 같은 실험을 따로 함), 감응식(참고), 무작위 |
| DQN | 5초마다 녹색 현시 4개 중 하나를 고른다. 보상 = −(감지 구간 정지 차량 + 진입 대기 차량). 학습 13일, 100,000단계, 학습 seed 3개. |
| 운영 규칙 | 보행 최소 녹색(길주로 횡단 46초, 석천로 횡단 33초), 보행 최대 대기(155초, 120초), 최대 녹색 120초, 정지선 차량 120초 대기 보장. DQN과 무작위 신호 모두 적용. |
| 시험 날짜 | 20220810(수), 20221028(금), 20220821(일), 20220910(추석 연휴 토) — 15분 시간대 384개 |

## 3. 검증한 것

- **신호 보정**: 19일 전체에서 1분 통과량이 보정 신호의 1분 녹색 시간과 같이 움직인다(직진·좌회전 8개 이동 상관 0.60~0.79, 시각 차 0초에서 최대). 자료 그대로는 −0.24~0.09. 자료 그대로 쓰면 시험 날짜에서도 차량 처리가 불가능하다(차량당 지연 436초, 미도착 10,586대).
- **보행 최소 녹색**: 도로 폭으로 계산한 46초가 실제 신호의 석천로 직진 녹색(5%·50%·95% = 46·47·50초)과 맞는다.
- **수요 재현**: 4일 모두 이동별 15분 교통량이 기록과 100% 같다. 실제 신호로 돌리면 90.1~92.5%가 15분 안에, 100%가 실행 끝까지 교차로를 건넌다.
- **운영 규칙**: 일부러 규칙을 어기려는 정책 5개 × 현시 구성 2개로 시험해 위반 0. 시험 날짜 평가에서도 DQN·무작위의 보행 규칙 위반 0.
- **학습 기록**: 운영 규칙이 바꾼 행동이 아니라 실제 실행된 행동을 학습에 쓰는지 시험한다(고치기 전에는 64%가 틀리게 저장됨).

## 4. 결과 (시험 4일, 384개 시간대)

### 실제 운영 신호 계열 — 주 결과

| 신호 | 차량당 평균 지연 | 차량당 평균 대기 | 평균 대기행렬 | 300초 이상 대기 |
|---|---:|---:|---:|---:|
| 고정신호(실제 운영) | 52.4초 | 40.6초 | 19.6대 | 407대 |
| 감응식(참고) | 48.1초 | 37.0초 | 17.9대 | 60대 |
| 무작위(0810만) | 54.5초 | 41.4초 | 22.0대 | 161대 |
| **DQN** | **42.1 ± 1.0초** | **31.2 ± 1.1초** | **15.2 ± 0.6대** | **2,764대** |

- 고정신호 대비 지연 −19.7%, 대기 −23.2%, 대기행렬 −22.4%. 384개 시간대의 97.4%에서 DQN이 더 좋았다(학습 seed별 95%·95%·92%).
- 시간대별 지연: 심야 40.3→28.1초, 오전 첨두 58.9→42.9초, 낮 51.1→44.6초, 오후 첨두 59.4→46.3초, 저녁 45.0→36.8초.
- **단점**: 300초 넘게 기다린 차량이 고정신호의 약 7배다. 대부분 길주로 서쪽 좌회전이다(이 방향 좌회전 차량의 19.7%, 고정신호는 1.3%). 보상이 '정지 차량 수의 합'이라 차량이 많은 직진을 우선하고, 좌회전은 차량 120초 대기 보장 규칙이 켤 때만 짧게 열린다. 줄이 조금씩 움직이면 연속 대기 시간이 다시 0부터 세어져, 누적 5분 대기를 막지 못한다.

## 5. 해석과 한계

- 실제 운영 신호를 기준으로, 보행 규칙을 지키면서도 평균 지연·대기·대기행렬을 약 20% 줄였다. 다만 **한 방향 좌회전을 오래 세우는 대가**가 있어 실제 운영에 그대로 쓸 수 있는 결과는 아니다.
- 다른 교차로 미반영 59건은 해결한 것이 아니라 범위에서 뺐다. 주변 신호가 만드는 차량 무리(소대) 효과가 없다.
- 15분 시간대마다 빈 도로에서 시작한다(앞 시간대 대기열이 이어지지 않음).
- 보행자는 움직이지 않고, 평행 직진 신호와 같이 건넌다고 가정해 신호 시간으로만 규칙을 정했다.
- 신호 보정은 강한 자료 근거가 있지만 현장 운영 기록으로 확인한 것은 아니다.
- DQN은 현시 순서를 자유롭게 고른다(실제 운영은 대개 순서 고정). 학습은 100,000단계 × seed 3개다.
